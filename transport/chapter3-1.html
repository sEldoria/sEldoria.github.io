3.0 ความรู้พื้นฐานที่จำเป็นก่อนเรียนบทที่ 3 (Essential Prerequisites)

[เสริมพื้นฐาน] คำว่า "หนึ่งมิติ (One-Dimensional)" หมายความว่าอุณหภูมิเป็นฟังก์ชันของพิกัดตำแหน่งเพียงตัวเดียว (เช่น T(x) หรือ T(r)) และความร้อนไหลในทิศทางนั้นเพียงทิศทางเดียว ส่วนคำว่า "สภาวะคงตัว (Steady-State)" หมายความว่าอุณหภูมิ ณ จุดใดๆ ไม่เปลี่ยนแปลงตามเวลา (∂T/∂t = 0) ส่งผลให้ไม่มีการสะสมพลังงานเพิ่มขึ้นในผนัง (Ėst = 0) ความรู้คณิตศาสตร์และฟิสิกส์พื้นฐานที่ใช้ในบทนี้ได้แก่: (1) การอินทิเกรตสองครั้ง: เมื่ออินทิเกรต d2T/dx2 = 0 ครั้งที่หนึ่งจะได้ dT/dx = C1 และอินทิเกรตครั้งที่สองจะได้สมการเส้นตรง T(x) = C1x + C2 ส่วนการอินทิเกรต dT/dr = C1/r จะได้ลอการิทึมธรรมชาติ T(r) = C1 ln(r) + C2 (โดยใช้สมบัติ ln(a) − ln(b) = ln(a/b)), และ (2) การรวมตัวต้านทานในวงจรไฟฟ้า: ตัวต้านทานต่ออนุกรมกันจะมีกระแสไหลเท่ากันและ Rtot = R1 + R2 + ... ส่วนตัวต้านทานต่อขนานกันจะมีแรงดันตกคร่อมเท่ากันและ 1/Req = 1/R1 + 1/R2

3.1 ผนังราบ (3.1 The Plane Wall)

[ต้นฉบับ: สไลด์หน้า 2–3] สำหรับการนำความร้อนใน 1 มิติผ่านผนังราบ อุณหภูมิจะเป็นฟังก์ชันของพิกัด x เพียงอย่างเดียว [T = T(x)] และความร้อนจะถูกถ่ายโอนในทิศทาง x นี้เท่านั้น ในรูปที่ 3.1a ผนังราบความหนา L ทำหน้าที่กั้นของไหลสองชนิดที่มีอุณหภูมิแตกต่างกัน คือ ของไหลร้อนด้านซ้าย (T∞,1, h1) และของไหลเย็นด้านขวา (T∞,2, h2) การถ่ายเทความร้อนเกิดขึ้นต่อเนื่องกัน 3 ขั้นตอนตามลำดับ ได้แก่: (1) การพาความร้อน จากของไหลร้อนที่ T∞,1 มายังผิวผนังด้านซ้ายที่ Ts,1, (2) การนำความร้อน ผ่านเนื้อผนังราบจาก x = 0 ไปยัง x = L, และ (3) การพาความร้อน จากผิวผนังด้านขวาที่ Ts,2 ออกไปยังของไหลเย็นที่ T∞,2

3.1.1 การกระจายอุณหภูมิและอัตราการนำความร้อน (Temperature Distribution and Conduction Rate)

[ต้นฉบับ: สไลด์หน้า 4–10] [แก้ไขจุดพิมพ์ผิดในสไลด์] การกระจายอุณหภูมิภายในผนังสามารถหาได้โดยการแก้สมการการแพร่ความร้อนพร้อมเงื่อนไขขอบเขตที่เหมาะสม สำหรับสภาวะคงตัว (∂T/∂t = 0) การนำความร้อน 1 มิติในทิศทาง x (∂T/∂y = ∂T/∂z = 0) และไม่มีแหล่งกำเนิดพลังงานความร้อนภายในผนัง (q̇ = 0) สมการการแพร่ความร้อนลดรูปลงเป็น:

ddx(k dTdx) = 0    หรือเนื่องจาก qx'' = −k(dT/dx) จะได้ว่า:    dqx''dx = 0  ⇒  qx'' = constant (ไม่ขึ้นกับ x) (สมการที่ 3.1)

หากกำหนดสมมติฐานว่าสภาพนำความร้อน k ของวัสดุผนังมีค่าคงตัว เราสามารถหารด้วย k แล้วอินทิเกรตสมการสองครั้งต่อเนื่องกันเพื่อหาผลเฉลยทั่วไป (General solution) ได้ดังนี้ (หมายเหตุ: ในสไลด์หน้า 6–9 พิมพ์ค่าคงที่ C1 เป็น Cr ในสมการ T(x) ซึ่งที่ถูกต้องคือ C1):

  • อินทิเกรตครั้งที่ 1: จาก d/dx(dT/dx) = 0 อินทิเกรตเทียบกับ x ได้ dT/dx = C1
  • อินทิเกรตครั้งที่ 2: อินทิเกรตเทียบกับ x อีกครั้ง ได้ผลเฉลยทั่วไปเป็นสมการเส้นตรง: T(x) = C1 x + C2
  • แทนเงื่อนไขขอบเขตชนิดที่ 1 (สไลด์หน้า 7–8): กำหนดอุณหภูมิที่ผิวทั้งสองด้านคือ ที่ x = 0 มี T(0) = Ts,1 และที่ x = L มี T(L) = Ts,2
    • แทนที่ x = 0: T(0) = C1(0) + C2 = Ts,1  ⇒  C2 = Ts,1
    • แทนที่ x = L: T(L) = C1 L + C2 = C1 L + Ts,1 = Ts,2  ⇒  C1 = (Ts,2 − Ts,1) / L

แทนค่า C1 และ C2 กลับลงในผลเฉลยทั่วไป จะได้ สมการการกระจายอุณหภูมิเชิงเส้นในผนังราบ (สไลด์หน้า 9):

T(x) = (Ts,2 − Ts,1L) x + Ts,1 = Ts,1 − (Ts,1 − Ts,2) xL (สมการที่ 3.2)

และเมื่อนำสมการที่ 3.2 ไปหาอนุพันธ์ dT/dx = (Ts,2 − Ts,1)/L แทนลงในกฎของฟูริเยร์ (สไลด์หน้า 10) จะได้อัตราการนำความร้อนและฟลักซ์ความร้อน:

qx = −k A dTdx = k AL (Ts,1 − Ts,2)     และ     qx'' = qxA = kL (Ts,1 − Ts,2) (สมการที่ 3.3)

3.1.2 ความต้านทานความร้อนและวงจรความร้อนสมมูล (3.1.2 Thermal Resistance & Equivalent Circuit)

[ต้นฉบับ: สไลด์หน้า 11–17] จากสมการที่ 3.3 จะเห็นว่ามีแนวคิดที่สำคัญมากเกิดขึ้นเมื่อเราเปรียบเทียบการแพร่ของพลังงานความร้อนกับการแพร่ของประจุไฟฟ้า (การนำไฟฟ้าตามกฎของโอห์ม, Ohm's law) หากเรานิยาม ความต้านทาน (Resistance) ว่าเป็น "อัตราส่วนระหว่างศักย์ขับเคลื่อน (Driving potential) ต่ออัตราการถ่ายโอนที่เกิดขึ้น (Transfer rate)" เราสามารถเปรียบเทียบระบบไฟฟ้าและระบบความร้อนได้ดังตารางที่ 3.1

องค์ประกอบของการเปรียบเทียบ การนำไฟฟ้า (Electrical Conduction - กฎของโอห์ม) การถ่ายเทความร้อน (Heat Transfer - กฎของฟูริเยร์/นิวตัน)
ศักย์ขับเคลื่อน (Driving Potential) ผลต่างศักย์ไฟฟ้า หรือแรงดันไฟฟ้า: ΔE = Es,1 − Es,2 [โวลต์, V] ผลต่างของอุณหภูมิ: ΔT = Ts,1 − Ts,2 [เคลวิน, K หรือ °C]
อัตราการไหล (Transfer Rate) กระแสไฟฟ้า (Electric Current): I [แอมแปร์, A] อัตราการถ่ายเทความร้อน (Heat Transfer Rate): qx [วัตต์, W]
สภาพนำของวัสดุ (Conductivity) สภาพนำไฟฟ้า: σ [หน่วย 1/(Ω·m)] สภาพนำความร้อน: k [หน่วย W/(m·K)]
นิยามความต้านทาน (Resistance) Re ≡ (Es,1 − Es,2) / I = L / (σ A) [โอห์ม, Ω] Rt,cond ≡ (Ts,1 − Ts,2) / qx = L / (k A) [หน่วย K/W]

ตารางที่ 3.1 [ต้นฉบับ: สไลด์หน้า 12–13] การอุปมาเปรียบเทียบระหว่างความต้านทานไฟฟ้าตามกฎของโอห์มกับความต้านทานความร้อน

สรุปสูตรความต้านทานความร้อนของผนังราบทั้ง 3 โหมด และการวิเคราะห์วงจรความร้อน (สไลด์หน้า 12–17)

  • 1. ความต้านทานความร้อนสำหรับการนำความร้อนในผนังราบ (Conduction Resistance, สไลด์หน้า 12):
    Rt,cond ≡ Ts,1 − Ts,2qx = Lk A     ⇒     qx = Ts,1 − Ts,2Rt,cond (สมการที่ 3.4)
  • 2. ความต้านทานความร้อนสำหรับการพาความร้อนที่พื้นผิว (Convection Resistance, สไลด์หน้า 14): จากกฎการเย็นตัวของนิวตัน qconv = h A (Ts − T∞):
    Rt,conv ≡ Ts − T∞qconv = 1h A     ⇒     qconv = Ts − T∞Rt,conv (สมการที่ 3.5)
  • 3. ความต้านทานความร้อนสำหรับการแผ่รังสีที่พื้นผิว (Radiation Resistance, สไลด์หน้า 15): จากสมการเชิงเส้น qrad = hr A (Ts − Tsur):
    Rt,rad ≡ Ts − Tsurqrad = 1hr A     (โดยที่ hr = ε σ (Ts + Tsur)(Ts2 + Tsur2)) (สมการที่ 3.6)
  • 4. การวิเคราะห์วงจรความร้อนสมมูลของผนังราบ (Equivalent Thermal Circuit, สไลด์หน้า 16–17):

    [แก้ไขจุดพิมพ์ผิดในสไลด์หน้า 16–17] พิจารณาวงจรความร้อนสมมูลในรูปที่ 3.1b เนื่องจากไม่มีการผลิตความร้อนภายในผนังและเป็นสภาวะคงตัว อัตราความร้อน qx จะมีค่าคงตัวเท่ากันตลอดทุกชิ้นส่วนที่ต่ออนุกรมกัน (หมายเหตุ: ในสไลด์หน้า 16 พิมพ์ตัวเศษคลาดเคลื่อนเป็น Ts,1 − Ts,1 และ Ts,2 − Ts,2 และหน้า 17 พิมพ์ตัวเศษเป็น Ts,1 − Ts,2 เมื่อหารด้วย Rtot ซึ่งที่ถูกต้องต้องใช้อุณหภูมิของไหล T∞,1 และ T∞,2 ดังนี้):

    qx = T∞,1 − Ts,11 / (h1A) = Ts,1 − Ts,2L / (kA) = Ts,2 − T∞,21 / (h2A) = T∞,1 − T∞,2Rtot   โดยที่   Rtot = 1h1A + LkA + 1h2A (สมการที่ 3.7)

3.1.3 ผนังประกอบ (3.1.3 The Composite Wall) และสัมประสิทธิ์การถ่ายเทความร้อนรวม (U)

[ต้นฉบับ: สไลด์หน้า 18–23] วงจรความร้อนสมมูลมีประโยชน์อย่างยิ่งสำหรับระบบที่ซับซ้อน เช่น ผนังประกอบ (Composite walls) ซึ่งประกอบด้วยชั้นของวัสดุต่างชนิดกันมาประกบกันทั้งแบบอนุกรม (Series) และแบบอนุกรม-ขนาน (Series-parallel) ตัวอย่างเช่น ผนังห้องเย็นที่ประกอบด้วยชั้นอิฐ ชั้นโฟมฉนวน และชั้นไม้ หรือผนังเตาอบหลายชั้น

วิธีทำอย่างละเอียด (ตามลำดับสไลด์หน้า 32–36 พร้อมคำนวณคำตอบสุดท้ายที่สไลด์เว้นไว้):

  • ขั้นที่ 1 วิเคราะห์ความต้านทานความร้อนรวมตั้งแต่ในเตาอบ (Ta = Tw = 400 °C) มาจนถึงผิวนอกหน้าต่าง (Ts,o = 50 °C):

    ที่ผิวด้านในของหน้าต่าง การพาความร้อน (hi) และการแผ่รังสี (hr) เกิดขึ้นพร้อมกันจากอุณหภูมิ 400 °C มายัง Ts,i จึงต่อกันแบบ ขนาน (Parallel) มีความต้านทานยุบรวมเป็น [(1/hiA)−1 + (1/hrA)−1]−1 = 1 / [A(hi + hr)] เมื่อนำมาบวกอนุกรมกับความต้านทานการนำความร้อนของพลาสติก A และ B (โดยแทนค่า LB = LA / 2 ตามโจทย์) จะได้ (สไลด์หน้า 32–33):

    ∑ Rt = 1A (1hi + hr + LAkA + LBkB) = 1A [1hi + hr + (1kA + 12kB) LA] (3.1a)
  • ขั้นที่ 2 ตั้งสมการสมดุลพลังงานที่พื้นผิวด้านนอกของหน้าต่าง (Ėin = Ėout, สไลด์หน้า 34–36):

    อัตราความร้อนที่ไหลผ่านหน้าต่างมาถึงผิวนอก Ėin = (Ta − Ts,o) / ∑Rt จะต้องเท่ากับอัตราความร้อนที่ระบายออกจากผิวนอกสู่อากาศในห้อง Ėout = ho A (Ts,o − T∞) เมื่อตัดพื้นที่ A ทั้งสองข้างและจัดรูปหาความหนา LA จะได้:

    LA = (1/ho)(Ta − Ts,o)/(Ts,o − T∞) − (hi + hr)−1[(1/kA) + (1 / 2kB)] = (1/25)(400 − 50)/(50 − 25) − (25 + 25)−1[(1/0.15) + 1/(2 × 0.08)] (3.1b)

[ต้นฉบับ: สไลด์หน้า 37] ระบบทรงกระบอกและทรงกลมในทางวิศวกรรมมักมีเกรเดียนต์ของอุณหภูมิเกิดขึ้นเฉพาะในแนวรัศมี (r) เพียงทิศทางเดียว จึงสามารถวิเคราะห์เสมือนเป็นระบบ 1 มิติ [T = T(r)] ได้ ในหัวข้อนี้เราจะวิเคราะห์การทำงานของท่อทรงกระบอกกลวงและเปลือกทรงกลมภายใต้สภาวะคงตัวเมื่อไม่มีการผลิตพลังงานความร้อนภายใน (q̇ = 0)

3.2.1 ทรงกระบอกกลวง (3.2.1 The Cylinder)

[ต้นฉบับ: สไลด์หน้า 37–41] ตัวอย่างที่พบบ่อยที่สุดคือท่อทรงกระบอกกลวง (Hollow cylinder) ที่มีความยาว L รัศมีภายใน r1 และรัศมีภายนอก r2 ซึ่งผิวด้านในและด้านนอกสัมผัสกับของไหลที่มีอุณหภูมิต่างกัน (T∞,1, h1 และ T∞,2, h2) ดังรูปที่ 3.5

การพิสูจน์การกระจายอุณหภูมิ อัตราความร้อน และความต้านทานของทรงกระบอกกลวง (สไลด์หน้า 38–50)

  • 1. สมการควบคุมและข้อสรุปเรื่องอัตราความร้อน qr (สไลด์หน้า 38–40): จากสมการที่ 2.14 สำหรับสภาวะคงตัว 1 มิติตามแนวรัศมีและไร้การผลิตความร้อน สมการการแพร่ความร้อนลดรูปเป็น:
    1r ddr(k r dTdr) = 0   ⇒   คูณด้วย −2πL:   ddr[−k (2πrL) dTdr] = ddr(qr) = 0 (สมการที่ 3.11)

    ข้อสังเกตสำคัญที่สุด (สไลด์หน้า 39–40): ในระบบแนวรัศมี เนื่องจากพื้นที่ผิวตั้งฉาก A(r) = 2π r L ขยายใหญ่ขึ้นตามรัศมี r ดังนั้น อัตราการนำความร้อน qr (หน่วย W) เท่านั้นที่มีค่าคงตัวไม่ขึ้นกับรัศมี r ส่วนฟลักซ์ความร้อน qr'' = qr / (2π r L) จะลดลงแปรผกผันกับรัศมี r!

  • 2. การอินทิเกรตสองครั้งและแทนเงื่อนไขขอบเขต (สไลด์หน้า 42–48): เมื่อ k คงตัว จาก d/dr(r dT/dr) = 0 อินทิเกรตครั้งที่ 1 ได้ r(dT/dr) = C1 หรือ dT/dr = C1 / r อินทิเกรตครั้งที่ 2 ได้ผลเฉลยทั่วไป: T(r) = C1 ln(r) + C2
    • แทนเงื่อนไขขอบเขต T(r1) = Ts,1 และ T(r2) = Ts,2: จะได้ Ts,1 = C1 ln(r1) + C2 และ Ts,2 = C1 ln(r2) + C2
    • นำสองสมการมาลบกัน: Ts,1 − Ts,2 = C1[ln(r1) − ln(r2)] = C1 ln(r1/r2)  ⇒  C1 = (Ts,1 − Ts,2) / ln(r1/r2)
    • แทนค่า C1 หา C2 = Ts,2 − [(Ts,1 − Ts,2)/ln(r1/r2)] ln(r2) แล้วแทนกลับใน T(r) จะได้ สมการการกระจายอุณหภูมิแบบลอการิทึม:
    T(r) = Ts,1 − Ts,2ln(r1 / r2) ln(rr2) + Ts,2 (สมการที่ 3.12)

[เสริมพื้นฐาน] ในผนังราบ การเพิ่มความหนาของฉนวนจะช่วยลดการสูญเสียความร้อนเสมอ แต่สำหรับท่อทรงกระบอกขนาดเล็กหรือลวดตัวนำไฟฟ้าที่มีรัศมีเปลือย ri เมื่อหุ้มฉนวนที่มีสภาพนำความร้อน k ให้มีรัศมีภายนอกเป็น r ความต้านทานรวมคือ Rtot(r) = ln(r/ri)/(2πkL) + 1/(2πrLh) เมื่อ r เพิ่มขึ้น ความต้านทานการนำความร้อนจะเพิ่มขึ้น แต่ความต้านทานการพาความร้อนที่ผิวนอกจะลดลง (เพราะพื้นที่ผิวพาความร้อน 2πrL ใหญ่ขึ้น!) หากหาอนุพันธ์ dRtot/dr = 1/(2πkLr) − 1/(2πhr2L) = 0 จะได้รัศมีที่ทำให้ความต้านทานรวมต่ำสุด (อัตราการถ่ายเทความร้อนสูงสุด) เรียกว่า รัศมีวิกฤตของฉนวน (Critical radius): rcr,ทรงกระบอก = k / h (และสำหรับทรงกลมคือ rcr,ทรงกลม = 2k / h) วิศวกรออกแบบสายไฟใช้หลักการนี้เลือกหุ้มฉนวนพลาสติกให้รัศมีใกล้เคียง rcr เพื่อช่วยระบายความร้อนออกจากสายไฟได้ดีขึ้น!
