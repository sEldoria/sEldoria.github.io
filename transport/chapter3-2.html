บทที่ 3: การนำความร้อนในหนึ่งมิติภายใต้สภาวะคงตัว (ส่วนที่ 2/2: การผลิตความร้อนภายในและแบบฝึกหัด)

ความต่อเนื่องจากส่วนที่ 1/2 และหลักการสำคัญเมื่อมีการผลิตพลังงานความร้อนภายใน (q̇ ≠ 0)

[เสริมพื้นฐาน] ในส่วนที่ 1/2 เราได้ศึกษาการนำความร้อนผ่านผนังราบ ทรงกระบอก และทรงกลมที่ไม่มีการผลิตความร้อนภายใน (q̇ = 0) ซึ่งมีคุณลักษณะสำคัญคือ อัตราการไหลของความร้อน q มีค่าคงตัวตลอดความหนาของวัสดุ จึงสามารถแทนวัสดุชิ้นนั้นด้วยตัวต้านทานความร้อน (Rt,cond) ได้ แต่ในส่วนที่ 2/2 นี้ (Bergman et al., 2011; อาชาไนย บัวศรี, 2560) เราจะศึกษา การนำความร้อนเมื่อมีการผลิตพลังงานความร้อนภายในตัวกลาง (q̇ > 0) ซึ่งพบในลวดทำความร้อนไฟฟ้า แท่งเชื้อเพลิงนิวเคลียร์ ถังเก็บกากกัมมันตรังสี และเครื่องปฏิกรณ์เคมีคายความร้อน ข้อควรจำสูงสุด: ในบริเวณของวัสดุที่มี q̇ ≠ 0 อัตราการนำความร้อน q(x) จะเพิ่มขึ้นตามระยะทาง (ไม่คงตัว) ดังนั้น ห้ามใช้สูตรความต้านทานความร้อน Rt,cond ในชั้นวัสดุที่มีการผลิตความร้อนภายในโดยเด็ดขาด! ต้องแก้สมการการแพร่ความร้อนหรือใช้สมดุลพลังงานของปริมาตรควบคุมเท่านั้น

3.4 การนำความร้อนเมื่อมีการผลิตพลังงานความร้อนภายใน (3.4 Conduction with Thermal Energy Generation)

[ต้นฉบับ: สไลด์หน้า 75] กระบวนการผลิตพลังงานความร้อนภายในตัวกลางที่พบบ่อยที่สุดคือ การเปลี่ยนรูปจากพลังงานไฟฟ้าเป็นพลังงานความร้อนในตัวกลางที่มีกระแสไฟฟ้าไหลผ่าน ซึ่งเรียกว่า การให้ความร้อนแบบโอห์มมิก หรือการให้ความร้อนด้วยความต้านทานไฟฟ้า (Ohmic or resistance heating) โดยหากกระแสไฟฟ้า I ไหลผ่านลวดตัวนำที่มีความต้านทานไฟฟ้า Re และมีปริมาตร V อย่างสม่ำเสมอ อัตราการผลิตความร้อนต่อหนึ่งหน่วยปริมาตรคือ q̇ = Ėg / V = I2 Re / V [หน่วย W/m3]

3.4.1 ผนังราบที่มีการผลิตความร้อนภายในอย่างสม่ำเสมอ (3.4.1 The Plane Wall)

[ต้นฉบับ: สไลด์หน้า 76–79] พิจารณาผนังราบที่มีความหนารวมเท่ากับ 2L โดยตั้งแกนพิกัด x = 0 ที่ระนาบกึ่งกลางผนัง (Midplane) ทำให้ขอบเขตผิวซ้ายอยู่ที่ x = −L และผิวขวาอยู่ที่ x = +L ภายในผนังมีการผลิตความร้อนต่อหน่วยปริมาตร q̇ อย่างสม่ำเสมอ ดังรูปที่ 3.9 ทั้ง 3 กรณี

กรณีที่ 1: ผนังราบที่มีเงื่อนไขขอบเขตไม่สมมาตร (Asymmetrical Boundary Conditions - สไลด์หน้า 79–83)

[ต้นฉบับ: สไลด์หน้า 79–83] พิจารณาผนังราบในรูปที่ 3.9a ซึ่งมีการผลิตความร้อนต่อหน่วยปริมาตร q̇ คงตัว และสภาพนำความร้อน k คงตัว สมการการแพร่ความร้อนใน 1 มิติ สภาวะคงตัว และการอินทิเกรตสองครั้งคือ:

d2Tdx2 + q̇k = 0   ⇒   อินทิเกรตครั้งที่ 1:   dTdx = −q̇k x + C1   ⇒   ผลเฉลยทั่วไป:   T(x) = −q̇2k x2 + C1 x + C2 (สมการที่ 3.20)

[เสริมพื้นฐาน: ขั้นตอนการแก้สมการหา C1 และ C2 ที่สไลด์หน้า 83 สรุปผลไว้] แทนเงื่อนไขขอบเขตทั้งสองด้านคือ ที่ผิวซ้าย x = −L มี T(−L) = Ts,1 และที่ผิวขวา x = +L มี T(+L) = Ts,2 ลงในสมการที่ 3.20:

  • สมการที่ (ก) แทน x = −L:   Ts,1 = −(q̇ / 2k) L2 − C1 L + C2
  • สมการที่ (ข) แทน x = +L:   Ts,2 = −(q̇ / 2k) L2 + C1 L + C2
  • นำสมการ (ข) ลบด้วย (ก):   Ts,2 − Ts,1 = 2 C1 L   ⇒   C1 = (Ts,2 − Ts,1) / (2L)
  • นำสมการ (ก) บวกกับ (ข):   Ts,1 + Ts,2 = −2(q̇ / 2k) L2 + 2 C2   ⇒   C2 = (q̇ L2) / (2k) + (Ts,1 + Ts,2) / 2

แทนค่า C1 และ C2 กลับลงในสมการที่ 3.20 จะได้ สมการการกระจายอุณหภูมิสำหรับผนังราบที่ไม่สมมาตร (สไลด์หน้า 83):

T(x) = q̇ L22k (1 − x2L2) + Ts,2 − Ts,12 xL + Ts,1 + Ts,22 (สมการที่ 3.21)

และเมื่อใช้กฎของฟูริเยร์ qx''(x) = −k(dT/dx) จะได้ฟลักซ์ความร้อน ณ ตำแหน่ง x ใดๆ คือ: qx''(x) = q̇ x − [k / (2L)](Ts,2 − Ts,1) (จะเห็นว่าฟลักซ์ความร้อนแปรผันเชิงเส้นกับตำแหน่ง x ไม่ใช่ค่าคงตัว!)

กรณีที่ 2 และ 3: เงื่อนไขขอบเขตสมมาตร (Symmetrical) และผนังหุ้มฉนวนที่ระนาบกึ่งกลาง (สไลด์หน้า 84–90)

[ต้นฉบับ: สไลด์หน้า 84–90] เมื่อพื้นผิวทั้งสองด้านถูกควบคุมให้มีอุณหภูมิเท่ากันคือ Ts,1 = Ts,2 ≡ Ts (หรือสัมผัสกับของไหลชนิดเดียวกันที่มี T∞,1 = T∞,2 = T∞ และ h1 = h2 = h ดังรูปที่ 3.9b) พจน์กลางของสมการที่ 3.21 จะเป็นศูนย์ทันที การกระจายอุณหภูมิจะสมมาตรรอบระนาบกึ่งกลาง (x = 0):

T(x) = q̇ L22k (1 − x2L2) + Ts (สมการที่ 3.22)
  • อุณหภูมิสูงสุดที่ระนาบกึ่งกลาง (x = 0, สไลด์หน้า 86–87): แทน x = 0 ลงในสมการที่ 3.22 จะได้อุณหภูมิสูงสุด T(0) ≡ T0 และรูปไร้มิติ (Nondimensional form):
    T0 = q̇ L22k + Ts     และรูปไร้มิติ:     T(x) − T0Ts − T0 = (xL)2 (สมการที่ 3.23)
  • ความสมมูลกับผนังความหนา L ที่หุ้มฉนวนด้านหนึ่ง (รูปที่ 3.9c, สไลด์หน้า 88–90): ที่ระนาบสมมาตร x = 0 เกรเดียนต์ของอุณหภูมิมีค่าเป็นศูนย์ [(dT/dx)|x=0 = 0] จึงไม่มีการถ่ายเทความร้อนข้ามระนาบนี้ ดังนั้น ครึ่งขวาของผนังสมมาตร (0 ≤ x ≤ L) จึงเหมือนกับ ผนังเดี่ยวความหนา L ที่หุ้มฉนวนสนิท (Adiabatic surface) ที่ด้าน x = 0 และระบายความร้อนด้วยการพาความร้อนที่ด้าน x = L ทุกประการ! เมื่อตั้งสมดุลพลังงานรวมของผนังความหนา L (Ėg = Ėout ต่อหน่วยพื้นที่ผิว):
    qcond''(L) = qconv''   ⇒   q̇ L = h (Ts − T∞)   ⇒   อุณหภูมิพื้นผิว:   Ts = T∞ + q̇ Lh (สมการที่ 3.24)

3.4.2 ระบบแนวรัศมีที่มีการผลิตความร้อนภายใน (3.4.2 Radial Systems with Generation)

[ต้นฉบับ: สไลด์หน้า 91–95] การผลิตพลังงานความร้อนภายในระบบแนวรัศมีมีความสำคัญอย่างยิ่งในการวิเคราะห์ลวดตัวนำไฟฟ้าทรงกระบอกตัน และแท่งเชื้อเพลิงนิวเคลียร์ (Nuclear fuel rods) พิจารณาทรงกระบอกตัน (Solid cylinder) รัศมี r0 ยาว L (L ≫ r0 เพื่อให้การนำความร้อนเป็น 1 มิติตามแนวรัศมี r) ที่มีการผลิตความร้อนต่อหน่วยปริมาตร q̇ สม่ำเสมอ และระบายความร้อนสู่ของไหลเย็น (T∞, h) ที่ผิวรอบนอก ดังรูปที่ 3.10

    แยกตัวแปรแล้วอินทิเกรตครั้งที่ 1 เทียบกับ r (โดยเมื่อ q̇ คงตัว อินทิเกรต r dr ได้ r2/2):

  • 2. แทนเงื่อนไขขอบเขตของทรงกระบอกตัน (สไลด์หน้า 93–94):
    • ที่เส้นแกนกลาง r = 0 (Centerline): เนื่องจากความสมมาตรรอบแกนกลาง เกรเดียนต์อุณหภูมิต้องเป็นศูนย์ [(dT/dr)|r=0 = 0] แทนในสมการ r(dT/dr) = −(q̇/2k)r2 + C1 ที่ r = 0 จะได้ทันทีว่า C1 = 0 (และในทางฟิสิกส์ อุณหภูมิที่ r = 0 ต้องมีค่าจำกัด ไม่เป็นอนันต์ เนื่องจาก ln(0) → −∞ ดังนั้นสัมประสิทธิ์ C1 ที่คูณอยู่กับ ln(r) จึงต้องเป็นศูนย์เสมอสำหรับทรงกระบอกตัน!)
    • ที่ผิวนอก r = r0: มี T(r0) = Ts แทนลงใน T(r) = −(q̇/4k)r2 + C2 จะได้ C2 = Ts + (q̇ / 4k) r02
    T(r) = q̇ r024k (1 − r2r02) + Ts     |     อุณหภูมิแกนกลาง: T0 = q̇ r024k + Ts     |     รูปไร้มิติ: T(r) − TsT0 − Ts = 1 − (rr0)2 (สมการที่ 3.27)

[เสริมพื้นฐาน] ในทำนองเดียวกัน สำหรับ ทรงกลมตัน (Solid sphere) รัศมี r1 ที่มีการผลิตความร้อนต่อหน่วยปริมาตร q̇ สม่ำเสมอ เมื่ออินทิเกรตสมการ (1/r2) d/dr(r2 dT/dr) + q̇/k = 0 สองครั้งและใช้เงื่อนไขสมมาตรที่จุดศูนย์กลาง (dT/dr)|r=0 = 0 กับอุณหภูมิผิว T(r1) = Ts,1 จะได้การกระจายอุณหภูมิเป็นพาราโบลาตัวหาร 6k คือ: T(r) = (q̇ r12 / 6k)[1 − (r/r1)2] + Ts,1 และอุณหภูมิสูงสุดที่จุดศูนย์กลางทรงกลมคือ T0 = T(0) = (q̇ r12) / (6k) + Ts,1 โดยอัตราความร้อนรวมที่ผลิตขึ้นภายในทรงกลมตันทั้งลูกคือ q = q̇ V = q̇ [(4/3)π r13] (สมการนี้จะใช้ในการแก้โจทย์แบบฝึกหัดข้อ 11 ท้ายบท)

3.5 ข้อผิดพลาดและความเข้าใจผิดที่พบบ่อยในบทที่ 3 (Common Pitfalls and How to Avoid Them)

  • ข้อผิดพลาดที่ 1 เผลอใช้สูตรความต้านทาน Rt,cond = L/(kA) ในวัสดุที่มีการผลิตความร้อนภายใน (q̇ ≠ 0): ดังที่เห็นในตัวอย่างที่ 3.3 เราใช้ความต้านทานความร้อน Rcond,B'' = LB/kB ได้เฉพาะในวัสดุ B ที่ไม่มีการผลิตความร้อน (q̇B = 0) เท่านั้น ส่วนในวัสดุ A ที่มี q̇A > 0 ต้องใช้สมการพาราโบลา T0 − T1 = q̇A LA2 / (2kA) เสมอ
  • ข้อผิดพลาดที่ 2 แทนค่ารัศมี r ด้วยเส้นผ่านศูนย์กลาง D ในพจน์ความต้านทานการพาความร้อนของท่อ: ในพจน์ ln(r2/r1) ของทรงกระบอก เนื่องจากเป็นอัตราส่วน เราจะแทนด้วยรัศมีหรือเส้นผ่านศูนย์กลางก็ได้ [ln(r2/r1) = ln(D2/D1)] แต่ในพจน์ความต้านทานการพาความร้อน 1/(2π r1 L h1) และในสมการทรงกลม [(1/r1) − (1/r2)] / (4π k) บังคับว่าต้องหารเส้นผ่านศูนย์กลางด้วย 2 ให้เป็นรัศมี r ก่อนแทนค่าเสมอ!
  • ข้อผิดพลาดที่ 3 สับสนเรื่องพื้นที่อ้างอิงของสัมประสิทธิ์การถ่ายเทความร้อนรวม (U) ในระบบทรงกระบอก: หากโจทย์ถามหาค่า U1 ที่อ้างอิงกับพื้นที่ผิวด้านใน (A1 = 2π r1 L) ต้องคูณ Rtot ด้วย A1 ตามสมการที่ 3.15 เสมอ

    −k dTdx|x=0 = 0     หรือ     dTdx|x=0 = 0 (เฉลย 6.2)

    • การนำความร้อนผ่านชั้นโฟม: Lfoam / kfoam = 0.08 / 0.024 = 3.3333 (m2·K)/W (สังเกตว่าโฟมเป็นตัวต้านทานหลักถึง 90%!)
    • การนำความร้อนผ่านชั้นไม้: Lwood / kwood = 0.015 / 0.17 = 0.0882 (m2·K)/W

1.การวิเคราะห์ระบบทางกายภาพ: ถังรูปทรงกลมมีโครงสร้างเป็นชั้นๆ โดยภายในโพรงทรงกลมรัศมี r1 = 0.20 m บรรจุกากกัมมันตรังสีที่ผลิตความร้อนอย่างสม่ำเสมอด้วยอัตราต่อหน่วยปริมาตร q̇ = 4.5 × 105 W/m3 ล้อมรอบด้วยเปลือกทรงกลมชั้นในทำจากตะกั่ว (r1 = 0.20 m ถึง r2 = 0.30 m, k1 = 35 W/(m·K), จุดหลอมเหลว Tmp = 328 °C) และเปลือกนอกทำจากเหล็กกล้าไร้สนิม (r2 = 0.30 m ถึง r3 = 0.34 m, k2 = 15.2 W/(m·K)) แช่อยู่ในน้ำเกลือที่ T∞ = 20 °C, h = 500 W/(m2·K)

2. เกณฑ์การตรวจสอบความเหมาะสมของการออกแบบ: ตะกั่วจะสัมผัสกับอุณหภูมิสูงสุดที่พื้นผิวด้านในสุดของชั้นตะกั่ว (Ts,1 ที่รัศมี r1 = 0.20 m) ดังนั้น การออกแบบนี้จะเป็นไปได้ก็ต่อเมื่อ Ts,1 < 328 °C

3. ขั้นตอนการคำนวณอย่างละเอียด:

  • ขั้นที่ 3.1 คำนวณอัตราการผลิตความร้อนรวมทั้งหมด (q) จากปริมาตรของกากกัมมันตรังสีภายในโพรงทรงกลมรัศมี r1 = 0.20 m:
    Vwaste = 43 π r13 = 43 π (0.20 m)3 = 0.03351 m3   ⇒   q = q̇ Vwaste = (4.5 × 105 W/m3)(0.03351 m3) = 15,079.6 W (15.08 kW) (เฉลย 11.1)
  • ขั้นที่ 3.2 คำนวณความต้านทานความร้อนของเปลือกตะกั่ว เปลือกเหล็กกล้าไร้สนิม และการพาความร้อนสู่บ่อน้ำเกลือ:

    เนื่องจากภายในเนื้อเปลือกตะกั่วและเปลือกเหล็กกล้าไร้สนิมไม่มีการผลิตความร้อน อัตราความร้อน q = 15,079.6 W จึงไหลผ่านความต้านทานทั้งสามที่ต่ออนุกรมกันโดยตรง (จากสมการที่ 3.19):

    • ความต้านทานการนำความร้อนของเปลือกตะกั่ว (r1 ถึง r2): Rt,lead = [(1/r1) − (1/r2)] / (4π k1) = [(1/0.20) − (1/0.30)] / (4π × 35) = 1.6667 / 439.82 = 0.003789 K/W
    • ความต้านทานการนำความร้อนของเปลือกเหล็กกล้าไร้สนิม (r2 ถึง r3): Rt,ss = [(1/r2) − (1/r3)] / (4π k2) = [(1/0.30) − (1/0.34)] / (4π × 15.2) = 0.39216 / 191.01 = 0.002053 K/W
    • ความต้านทานการพาความร้อนที่ผิวนอก (r3 = 0.34 m): Rt,conv = 1 / (h · 4π r32) = 1 / [500 × 4π × (0.34)2] = 1 / 726.34 = 0.001377 K/W
    • รวมความต้านทานทั้งหมด: Rtot = 0.003789 + 0.002053 + 0.001377 = 0.007219 K/W
  • ขั้นที่ 3.3 คำนวณอุณหภูมิสูงสุดของชั้นตะกั่วที่ผิวใน (Ts,1) และสรุปผลการตรวจสอบ:
    Ts,1 = T∞ + q Rtot = 20 °C + (15,079.6 W × 0.007219 K/W) = 20 + 108.86 = 128.86 °C (เฉลย 11.2)

    สรุปผลการตรวจสอบการออกแบบ: เนื่องจากอุณหภูมิสูงสุดของเปลือกตะกั่ว (Ts,1 = 128.86 °C) มีค่าต่ำกว่าจุดหลอมเหลวของตะกั่ว (328 °C) อย่างมาก (มีส่วนเผื่อความปลอดภัยเกือบ 200 °C) และแม้แต่ในกรณีที่กากกัมมันตรังสีเป็นของแข็งที่มี k = 35 W/(m·K) เท่ากับตะกั่ว อุณหภูมิที่จุดศูนย์กลางสุด T(0) = Ts,1 + q̇ r12/(6k) = 128.86 + 85.71 = 214.57 °C ก็ยังคงต่ำกว่า 328 °C ดังนั้น การออกแบบถังรูปทรงกลมนี้มีความปลอดภัยและอยู่ในเกณฑ์ที่เป็นไปได้ (Feasible and Safe)

อภิธานศัพท์วิชาการสำคัญ (Glossary of Technical Terms)

คำศัพท์ภาษาไทย คำศัพท์ภาษาอังกฤษ คำอธิบายความหมายโดยสรุป
พื้นผิวอะเดียแบติก / หุ้มฉนวน Adiabatic / Insulated Surface พื้นผิวที่ไม่มีการถ่ายเทความร้อนไหลผ่าน (q'' = 0) ทำให้เกรเดียนต์อุณหภูมิตั้งฉากกับผิวเป็นศูนย์ (∂T/∂n = 0)
วัสดุไอโซทรอปิก Isotropic Material วัสดุที่มีสมบัติทางกายภาพ (เช่น สภาพนำความร้อน k) เท่ากันในทุกทิศทาง (kx = ky = kz = k)
สัมประสิทธิ์การถ่ายเทความร้อนรวม Overall Heat Transfer Coefficient (U) สัมประสิทธิ์ที่รวมผลของความต้านทานการนำและการพาความร้อนทุกชั้นเข้าด้วยกัน นิยามโดย UA = 1/Rtot
ความต้านทานการสัมผัสทางความร้อน Thermal Contact Resistance (Rt,c'') ความต้านทานที่รอยต่อของของแข็งสองชนิดอันเกิดจากความขรุขระระดับจุลภาคทำให้เกิดช่องว่างกักเก็บของไหล
สภาพแพร่ความร้อน Thermal Diffusivity (α) อัตราส่วนระหว่างสภาพนำความร้อนต่อความจุความร้อนเชิงปริมาตร (α = k/ρcp) บ่งบอกความเร็วในการแพร่ของอุณหภูมิ
