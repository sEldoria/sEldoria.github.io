บทที่ 6: การไหลภายนอก (Chapter 6: External Flow)

เรียบเรียงจากเอกสารการสอนของอาจารย์ (สไลด์หน้า 34–91) ครอบคลุมการไหลขนานแผ่นราบ ทรงกระบอก และทรงกลม พร้อมตัวอย่างคำนวณและแบบฝึกหัดอย่างละเอียด

6.0 บทนำและวัตถุประสงค์การเรียนรู้บทที่ 6 [สไลด์หน้า 34–40]

ในการศึกษาบทที่ 6 นี้ เรามุ่งเน้นปัญหาการคำนวณอัตราการถ่ายโอนความร้อนจากพื้นผิวใน การไหลภายนอก (External flow) ซึ่งเป็นลักษณะการไหลที่ชั้นชิดผิว (Boundary layers) สามารถพัฒนาได้อย่างอิสระโดยไม่มีข้อจำกัดหรือผนังกั้นจากพื้นผิวรอบข้าง (แตกต่างจากการไหลภายในท่อ) ตัวอย่างเช่น การไหลของอากาศผ่านแผ่นราบ การไหลผ่านท่อทรงกระบอก ทรงกลม หรือใบพัดกังหัน [สไลด์หน้า 35–36] โดยเราจะพิจารณาเฉพาะการพาความร้อนแบบบังคับ (Forced convection) ความเร็วต่ำ และไม่มีการเปลี่ยนสถานะ (No phase change) [สไลด์หน้า 37]

6.1 วิธีเชิงประจักษ์ (The Empirical Method) [สไลด์หน้า 41–45]

[เสริมพื้นฐาน] เนื่องจากสมการอนุรักษ์ของการไหลภายนอกมีความซับซ้อนทางคณิตศาสตร์สูง (ໂດຍเฉพาะเมื่อเข้าสู่เขตปั่นป่วน) วิศวกรรมจึงต้องอาศัย วิธีเชิงประจักษ์ (Empirical method) ซึ่งเป็นการทดลองวัดค่าการถ่ายโอนความร้อนในห้องปฏิบัติการภายใต้สภาวะควบคุม แล้วนำผลมาจัดกลุ่มในรูปตัวแปรไร้มิติ [สไลด์หน้า 41]

หลักการทดลองวัดค่า h̄L (สไลด์หน้า 41–42): พิจารณาแผ่นราบที่ติดตั้งฮีตเตอร์ไฟฟ้าอิสระเพื่อให้ความร้อนรักษาอุณหภูมิผิว Ts > T∞ เมื่ออากาศไหลผ่าน เราสามารถวัดพลังงานความร้อนรวม q จากกำลังไฟฟ้าทางไฟฟ้า E · I แล้วคำนวณหาค่าสัมประสิทธิ์การพาความร้อนเฉลี่ย h̄L ได้จากกฎการเย็นตัวของนิวตัน q = E · I = h̄L As (Ts − T∞) เมื่อทำการทดลองเปลี่ยนความเร็ว u∞ ความยาวแผ่น L และเปลี่ยนชนิดของไหล (เช่น อากาศ น้ำ น้ำมันเครื่อง ซึ่งมีค่า Pr ต่างกัน) เราจะได้ชุดข้อมูลค่านัสเซลต์ NuL ที่สอดคล้องกับ ReL และ Pr จำนวนมาก [สไลด์หน้า 42] เมื่อนำมาพล็อตกราฟ Log-Log จะได้เส้นตรงที่สอดคล้องกับสมการสหสัมพันธ์ทั่วไป [สไลด์หน้า 43–44]:

NūL = C · ReLm · Prn   (สมการสหสัมพันธ์เชิงประจักษ์ทั่วไป) [สไลด์หน้า 44]

และเนื่องจากสมบัติของของไหลแปรผันตามอุณหภูมิ ในการคำนวณจริงจึงต้องประเมินสมบัติทุกตัวที่ อุณหภูมิฟิล์ม (Film temperature, Tf) ซึ่งนิยามเป็นค่าเฉลี่ยเลขคณิตระหว่างอุณหภูมิผิวกับอุณหภูมิกระแสอิสระ [สไลด์หน้า 45]:

Tf ≡ Ts + T∞2   (นิยามอุณหภูมิฟิล์ม) [สไลด์หน้า 45]

6.2 แผ่นราบในการไหลแบบขนาน (The Flat Plate in Parallel Flow) [สไลด์หน้า 46–66]

6.2.1 การไหลแบบราบเรียบ (Laminar Flow, Pr ≥ 0.6) [สไลด์หน้า 47–50]

สำหรับการไหลแบบราบเรียบบนแผ่นราบอุณหภูมิคงที่ โพนฮาวเซนและพฮาวเซน (Pohlhausen) ได้แก้สมการชั้นชิดผิวและได้ผลเฉลยสำหรับตัวเลขนัสเซลต์เฉพาะจุด สัมประสิทธิ์ความเสียดทาน และความหนาสัมพัทธ์ของชั้นชิดผิว ดังนี้ [สไลด์หน้า 47–48]:

Nux = hx xk = 0.332 Rex1/2 Pr1/3   (Pr ≥ 0.6)   …(สมการที่ 1)
C̄f,x = 1.328 Rex−1/2   ,   δδt ≈ Pr1/3
NūL = h̄ Lk = 0.664 ReL1/2 Pr1/3   (Pr ≥ 0.6)   …(สมการที่ 2)   [สไลด์หน้า 47–48]

[เสริมพื้นฐาน] ที่มาของสมการที่ (2): หาได้จากการอินทิเกรตค่าเฉพาะจุด h̄ = (1/L)∫0L hx dx = (1/L)∫0L 0.332 (u∞/ν x)1/2 Pr1/3 k dx ซึ่งเมื่ออินทิเกรตแล้วจะได้ค่าคงที่เพิ่มขึ้นจาก 0.332 เป็น 2 × 0.332 = 0.664 (ดังที่พิสูจน์ไว้แล้วในตัวอย่าง 5.2 ของบทที่ 5)

กรณีโลหะเหลว (Pr ≤ 0.05, Pex ≥ 100): เนื่องจากโลหะเหลวมีค่า Pr น้อยมาก การพาความร้อนจึงถูกครอบงำด้วยการแพร่ความร้อนอย่างรวดเร็ว สมการเฉพาะจุดจึงเปลี่ยนเป็น [สไลด์หน้า 49]:

Nux = 0.565 Pex1/2   (Pr ≤ 0.05, Pex ≥ 100, โดย Pex ≡ Rex Pr)   …(สมการที่ 3) [สไลด์หน้า 49]

สหสัมพันธ์ครอบคลุมทุกค่า Pr (ของ Churchill & Ozoe): สำหรับแผ่นราบอุณหภูมิคงที่ที่ใช้ได้กับทุกค่า Prandtl number เมื่อ Pex ≥ 100 [สไลด์หน้า 50]:

Nux = 0.3387 Rex1/2 Pr1/3[1 + (0.0468 / Pr)2/3]1/4   …(สมการที่ 4)  และค่าเฉลี่ยคือ Nūx = 2 Nux   …(สมการที่ 5) [สไลด์หน้า 50]

6.2.2 การไหลแบบปั่นป่วน (Turbulent Flow, Rex ≤ 107) [สไลด์หน้า 51–54]

จากการทดลอง สำหรับการไหลแบบปั่นป่วนที่มี Rex ≤ 107 สัมประสิทธิ์ความเสียดทานและความหนาชั้นชิดผิวความเร็วคือ [สไลด์หน้า 51]:

Cf,x = 0.0592 Rex−1/5   ,   δ = 0.37 x Rex−1/5 [สไลด์หน้า 51]

เมื่ออาศัย Chilton-Colburn Analogy ระหว่างโมเมนตัมและความร้อน (St · Pr2/3 = Cf,x / 2) จะได้นัสเซลต์เฉพาะจุดและนัสเซลต์เฉลี่ยสำหรับการไหลแบบปั่นป่วนตลอดทั้งแผ่น ดังนี้ [สไลด์หน้า 52–54]:

Nux = 0.0296 Rex4/5 Pr1/3   (0.6 < Pr < 60)   …(สมการที่ 6)
NūL = 0.037 ReL4/5 Pr1/3   (0.6 < Pr < 60, ReL ≤ 107)   …(สมการที่ 7) [สไลด์หน้า 52, 54]

6.2.3 สภาวะชั้นชิดผิวแบบผสม (Mixed Boundary Layer Conditions) [สไลด์หน้า 55–59]

ในความเป็นจริง การไหลบนแผ่นราบมักเริ่มต้นด้วยเขตราบเรียบตั้งแต่ขอบนำ แล้วจึงเกิดการเปลี่ยนผ่านไปสู่เขตปั่นป่วนที่ตำแหน่งวิกฤต xc (หรือกำหนดด้วย Rex,c = 5 × 105) หากตำแหน่งเปลี่ยนผ่านไม่ได้อยู่ชิดติดปลายแผ่น ($x_c/L \le 0.95$) ค่าสัมประสิทธิ์เฉลี่ยจะได้รับอิทธิพลจากทั้งสองเขต [สไลด์หน้า 55–56] โดยได้จากการอินทิเกรตช่วงราบเรียบและปั่นป่วนรวมกัน:

NūL = (0.037 ReL4/5 − A) Pr1/3   โดยที่ A = 0.037 Rex,c4/5 − 0.664 Rex,c1/2 [สไลด์หน้า 57]

เมื่อแทนค่ามาตรฐาน Rex,c = 5 × 105 เราจะได้ค่าคงที่ A = 871 ทำให้สมการสหสัมพันธ์สำหรับแผ่นราบในสภาวะชั้นชิดผิวแบบผสม (Mixed boundary layer) คือ [สไลด์หน้า 58–59]:

NūL = (0.037 ReL4/5 − 871) Pr1/3   (0.6 ≤ Pr ≤ 60, 5 × 105 ≤ ReL ≤ 108)   …(สมการที่ 8)
C̄f,L = 0.074ReL1/5 − 1,742ReL   และเมื่อ ReL ≫ Rex,c จะลดรูปเหลือ: NūL = 0.037 ReL4/5 Pr1/3  …(สมการที่ 9) [สไลด์หน้า 58–59]

6.2.4 กรณีพิเศษ: ช่วงเริ่มต้นไม่ให้ความร้อน (Unheated Starting Length) [สไลด์หน้า 60–65]

ในงานวิศวกรรมบางกรณี แผ่นราบอาจมีช่วงต้นน้ำยาว ξ ที่มีอุณหภูมิเท่ากับกระแสอิสระ (T_s = T_\infty, จึงยังไม่มีการถ่ายโอนความร้อน) และเริ่มต้นให้ความร้อนที่ตำแหน่ง x = ξ เป็นต้นไป (T_s ≠ T_\infty, รูปที่ 6.4) ทำให้ชั้นชิดผิวความเร็วเริ่มต้นที่ x = 0 แต่ชั้นชิดผิวความร้อนเริ่มต้นที่ x = ξ [สไลด์หน้า 60–61] โดยนัสเซลต์เฉพาะจุดและค่าเฉลี่ยคำนวณจากสูตรดัดแปลงดังนี้ [สไลด์หน้า 61–65]:

Nux(Laminar) = Nux|ξ=0[1 − (ξ / x)3/4]1/3   …(สมการที่ 10)  ,  Nux(Turbulent) = Nux|ξ=0[1 − (ξ / x)9/10]1/9  …(สมการที่ 11)
NūL = NūL|ξ=0 · LL − ξ [ 1 − (ξL)p+1 / p+2 ]p / p+1   (โดย p = 2 สำหรับราบเรียบ, p = 8 สำหรับปั่นป่วน)  …(สมการที่ 12–13) [สไลด์หน้า 61–65]

หากแผ่นราบได้รับฟลักซ์ความร้อนสม่ำเสมอ q''_s คงที่ตลอดแผ่น (แทนที่จะเป็นอุณหภูมิผิวคงที่ T_s) ค่าตัวเลขนัสเซลต์จะสูงกว่าเล็กน้อย [สไลด์หน้า 66]:

6.3 ระเบียบวิธีมาตรฐานในการคำนวณการพาความร้อน และตัวอย่างที่ 6.1 [สไลด์หน้า 67–77]

ก่อนเลือกใช้สมการสหสัมพันธ์สำหรับปัญหาการพาความร้อนใด ๆ ให้ปฏิบัติตาม กฎมาตรฐาน 5 ข้อ อย่างเคร่งครัด: (1) ระบุรูปทรงเรขาคณิตให้ชัดเจน, (2) เลือกอุณหภูมิฟิล์ม T_f และเปิดตารางหาค่าสมบัติของของไหล, (3) คำนวณตัวเลขเรย์โนลด์สเพื่อตรวจสอบระเบียบการไหลว่าเป็นแบบราบเรียบหรือปั่นป่วน, (4) พิจารณาว่าต้องการค่าเฉพาะจุดหรือค่าเฉลี่ย, และ (5) เลือกสมการสหสัมพันธ์ที่ถูกต้องเหมาะสม [สไลด์หน้า 67–69]

[เสริมพื้นฐาน] ตัวอย่างที่ 6.1 (สไลด์หน้า 70–77): การระบายความร้อนแผ่นราบด้วยอากาศความดันต่ำ

โจทย์: อากาศที่ความดัน p∞ = 6 kN/m2 และอุณหภูมิ T∞ = 300°C ไหลด้วยความเร็ว u∞ = 10 m/s ผ่านแผ่นราบความยาว L = 0.5 m (ความกว้างต่อหนึ่งหน่วยความกว้าง w = 1.0 m) ซึ่งถูกรักษาให้อุณหภูมิพื้นผิวอยู่ที่ Ts = 27°C จงคำนวณหาอัตราการระบายความร้อนต่อหนึ่งหน่วยความกว้าง q' (W/m) [สไลด์หน้า 70–71]

วิธีทำอย่างละเอียด (เติมเต็มช่องว่างที่เว้นไว้ในสไลด์หน้า 73–77):
1. ประเมินอุณหภูมิฟิล์ม (T_f): T_f = (300 + 27)/2 + 273.15 = 163.5 + 273.15 = 436.65 ≈ 437 K (เปิดตารางสมบัติอากาศที่ 1 atm ที่ 400 K และ 450 K แล้วทำ Linear interpolation จะได้ค่าสมบัติที่ 437 K ดังนี้: k = 0.0364 W/(m·K), Pr = 0.687, ν1 = 30.84 × 10−6 m2/s ที่ 1 atm หรือ p_1 = 1.0133 × 105 N/m2) [สไลด์หน้า 73]
2. ปรับแก้ความหนืดจลน์ตามความดันจริง (p2 = 6 kN/m2): เนื่องจากความหนืดจลน์แปรผกผันกับความดันตามกฎแก๊สอุดมคติ (ν2 = ν1 · (p1 / p2)) [สไลด์หน้า 74–75]:
ν2 = 30.84 × 10−6 m2/s × 1.0133 × 105 N/m26 × 103 N/m2 = 30.84 × 10−6 × 16.888 = 5.21 × 10−4 m2/s
3. คำนวณตัวเลขเรย์โนลด์ส (ReL): ReL = u∞ Lν2 = (10 m/s)(0.5 m)5.21 × 10−4 m2/s = 5.05.21 × 10−4 = 9,597 (เนื่องจาก ReL < 5 × 105 การไหลจึงเป็นแบบราบเรียบตลอดทั้งแผ่น) [สไลด์หน้า 76]
4. คำนวณตัวเลขนัสเซลต์และสัมประสิทธิ์การพาความร้อนเฉลี่ย (h̄): ใช้สมการที่ (2) สำหรับแผ่นราบราบเรียบ [สไลด์หน้า 77]:
NūL = 0.664 ReL1/2 Pr1/3 = 0.664 (9,597)1/2 (0.687)1/3 = 0.664 (97.96)(0.8823) = 57.4
h̄ = NūL · kL = 57.4 × 0.0364 W/(m·K)0.5 m = 2.08940.5 = 4.18 W/(m2·K)
5. คำนวณอัตราการระบายความร้อนต่อหนึ่งหน่วยความกว้าง (q'): จากกฎการเย็นตัวของนิวตัน [สไลด์หน้า 77]:
q' = qw = h̄ · L · (T∞ − Ts) = (4.18 W/m2·K)(0.5 m)(300 − 27)°C = 2.09 × 273 = 570.6 W/m

6.4 ทรงกระบอกในการไหลขวาง (The Cylinder in Cross Flow) [สไลด์หน้า 78–87]

อีกหนึ่งการไหลภายนอกที่พบได้บ่อยในงานวิศวกรรมคือ การไหลของของไหลตัดผ่านตั้งฉากกับแกนของท่อทรงกระบอกกลม (Cross flow over a circular cylinder) ดังแสดงใน รูปที่ 6.5 [สไลด์หน้า 78–79]

6.4.1 กลศาสตร์การไหลและการหลุดลอกของชั้นชิดผิวบนทรงกระบอก (สไลด์หน้า 78–83)

  • จุดหยุดนิ่งด้านหน้า (Forward stagnation point): เมื่อของไหลปะทะด้านหน้าสุดของทรงกระบอก ความเร็วของไหลจะลดลงเป็นศูนย์อย่างกะทันหัน เกิดการสะสมของความดันสูงขึ้น (Favorable pressure gradient, dp/dx < 0) ในครึ่งวงกลมด้านหน้า [สไลด์หน้า 79–80]
  • เกรเดียนต์ความดันต้าน (Adverse pressure gradient) และจุดหลุดลอก (Separation point): เมื่อของไหลเคลื่อนที่อ้อมผ่านครึ่งวงกลมหลัง ความดันจะเริ่มสูงขึ้นอีกครั้ง ทำให้เกิดเกรเดียนต์ความดันต้าน (dp/dx > 0) อนุภาคของไหลที่อยู่ติดผิวสูญเสียโมเมนตัมจนไม่สามารถเอาชนะความดันต้านได้ ทำให้การไหลหยุดนิ่งและเกิดการย้อนกลับ เกิดเป็น จุดหลุดลอก (Separation point) ซึ่งชั้นชิดผิวจะหลุดออกจากผิววัตถุ กลายเป็น เขตน้ำวน (Wake) ด้านหลังทรงกระบอกที่มีการหมุนวนและปั่นป่วนสูง Re_D) ต่อจุดหลุดลอก: หากเพิ่มความเร็วให้สูงจนเกิดการเปลี่ยนผ่านเป็นเขตปั่นป่วนก่อนเกิดการหลุดลอก (Re_D ≥ 2 × 105) การไหลแบบปั่นป่วนจะมีพลังงานสูงกว่า ทำให้สามารถเคลื่อนที่อ้อมไปได้ไกลขึ้น ส่งผลให้จุดหลุดลอกถูกเลื่อนไปทางด้านหลังของทรงกระบอกมากขึ้น [สไลด์หน้า 82–83]
ตำราเรียนปรากฏการณ์การขนส่ง 1 (Transport Phenomena I) — บทที่ 6: การไหลภายนอก หน้า 5

6.5.1 เฉลยละเอียดแบบฝึกหัดข้อ (13) ท้ายบทที่ 6 (สไลด์หน้า 90–91)

[เฉลยละเอียด] แบบฝึกหัดข้อ 13: แผ่นราบความกว้าง w = 1 m ติดตั้งแถบฮีตเตอร์แยกส่วนความยาว 50 มม.

โจทย์: แผ่นราบกว้าง w = 1 m รักษาอุณหภูมิผิวคงที่ T_s = 230°C ด้วยแถบฮีตเตอร์ไฟฟ้าอิสระแต่ละแถบยาว Li = 50 mm (0.05 m) อากาศบรรยากาศที่ T_\infty = 25°C ไหลผ่านด้วยความเร็ว u_\infty = 60 m/s ถามว่า ฮีตเตอร์หมายเลขใด (นับจากขอบนำ) ที่ต้องใช้กำลังไฟฟ้าสูงสุด และมีค่าเท่าใด? [สไลด์หน้า 90–91]
วิธีทำอย่างละเอียด:
1. เปิดตารางสมบัติอากาศที่อุณหภูมิฟิล์ม T_f = (230 + 25)/2 + 273.15 = 300.5 + 273.15 = 573.65 ≈ 574 K จะได้ k = 0.0439 W/(m·K), ν = 4.88 × 10−5 m2/s, Pr = 0.680
2. เนื่องจากฟลักซ์ความร้อนเฉพาะจุดแปรผันตาม q''x(x) = hx(T_s − T_\infty) และค่าสัมประสิทธิ์เฉพาะจุด hx ในเขตราบเรียบแปรผันตาม x−1/2 ดังนั้น ค่า hx และฟลักซ์ความร้อนจะสูงสุดที่ขอบนำของแต่ละแถบ (จุดเริ่มต้นที่ใกล้ขอบนำที่สุด) หากพิจารณาแถบฮีตเตอร์ย่อย: แถบที่ 1 อยู่ชิดขอบนำที่สุด ($x$ น้อยที่สุด) จะมีค่า $h$ สูงที่สุด แต่เนื่องจากโจทย์ถามหาฮีตเตอร์หมายเลขใดที่ใช้กำลังไฟฟ้าสูงสุด (ซึ่งพิจารณาจากอัตราความร้อนรวม $q_i$ ของแต่ละแถบ ซึ่งพื้นที่แถบเท่ากัน แต่ค่าสัมประสิทธิ์เฉลี่ยของแถบแรกสุด $\overline{h}_1$ สูงสุดเนื่องจากชั้นชิดิฟวบางที่สุด) ดังนั้นฮีตเตอร์หมายเลข 1 (ที่ระยะ $x = 0$ ถึง $0.05$ ม.) จึงต้องใช้กำลังไฟฟ้าสูงสุด
3. คำนวณค่าเรย์โนลด์สที่ปลายแถบที่ 1 ($x_1 = 0.05 m$): Re1 = u∞ x1ν = (60 m/s)(0.05 m)4.88 × 10−5 m2/s = 61,475 (< 5 × 105 เป็นแบบราบเรียบ)
4. คำนวณค่าสัมประสิทธิ์เฉลี่ยของแถบที่ 1: h̄1 = 2 · k · 0.332 Re11/2 Pr1/3x1 = 2(0.0439)(0.332)(247.9)(0.879)0.05 = 143.2 W/(m2·K)
5. กำลังไฟฟ้าสูงสุดของฮีตเตอร์แถบที่ 1: q1 = h̄1 · (w · L1) · (T_s − T_\infty) = (143.2)(1 × 0.05)(230 − 25) = 7.16 × 205 = 1,467.8 W (หรือ 1.468 kW)

6.5.2 เฉลยละเอียดแบบฝึกหัดข้อ (14) ท้ายบทที่ 8 (สไลด์หน้า 180)

โจทย์: น้ำอุณหภูมิ T_\infty = 20°C ไหลขวางท่วมวัตถุทรงกลมเส้นผ่านศูนย์กลาง D = 20 mm (0.02 m) ด้วยความเร็ว V = 2 m/s อุณหภูมิผิวทรงกลม T_s = 80°C จงคำนวณหาอัตราการถ่ายโอนความร้อนออกจากทรงกลม q [สไลด์หน้า 180]

6.6 สรุปสาระสำคัญประจำบทที่ 6 และคำถามทบทวน

สรุปสาระสำคัญ: บทที่ 6 นำเสนอวิธีคำนวณสัมประสิทธิ์การพาความร้อนในการไหลภายนอก โดยหัวใจสำคัญคือการคำนวณตัวเลขเรย์โนลด์ส ($Re$) เพื่อจำแนกประเภทการไหล (ราบเรียบเทียบกับปั่นป่วน) เลือกใช้สหสัมพันธ์ของแผ่นราบ ทรงกระบอก หรือทรงกลมอย่างเหมาะสม และประเมินสมบัติที่อุณหภูมิฟิล์ม ($T_f$)

คำถามทบทวน: (1) ทำไม ณ ตำแหน่งเริ่มต้น (ขอบนำ $x=0$) ของแผ่นราบ สัมประสิทธิ์การพาความร้อนเฉพาะจุดจึงมีค่าสูงมากเป็นอนันต์? (2) ปรากฏการณ์การหลุดลอกของชั้นชิดผิว (Boundary layer separation) บนทรงกระบอกส่งผลอย่างไรต่ออัตราการถ่ายโอนความร้อนด้านหลังกระบอก?
