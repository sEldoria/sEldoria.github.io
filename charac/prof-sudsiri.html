แก๊ส X และ Y ดูดซับบนตัวเร่งปฏิกิริยาของแข็งพร้อมกัน โดยมีอัตราการดูดซับและการคายซับเป็นอันดับหนึ่งเชิงโมเลกุล จงพิสูจน์ว่าสัดส่วนการปกคลุมผิว (Fractional Surface Coverage) θX และ θY เป็นดังนี้:
θX = (KX pX) / (1 + KX pX + KY pY) และ θY = (KY pY) / (1 + KX pX + KY pY)

เฉลยตัวอย่างที่ 5.1 (สไลด์บทที่ 5 หน้า 35-40):
ปฏิกิริยา A + B → P, โดย CA0 = CB0 = 0.02 mol/L ⇒ ปฏิกิริยาอันดับสอง -rA = k CA2 (k = 500 L/(mol·min))
คำนวณสเปซไทม์ PFR: τp = V / v = 0.5 L / (0.10 L/min) = 5 min
กลุ่มตัวแปรไร้มิติ: k CA0 τp = 500 × 0.02 × 5 = 50
(ก) หา XA ใน PFR: จากสมการ PFR ปฏิกิริยาอันดับสอง: k CA0 τp = XA / (1 - XA) ⇒ 50 = XA / (1 - XA) ⇒ 50 - 50 XA = XA ⇒ XA = 50/51 ≈ 0.9804 (98.04%) (หรืออ่านจากรูปที่ 5.7 ที่ k CA0 τ = 50 ได้ 1 - XA ≈ 0.02)
(ข) ขนาด CSTR ที่ได้ XA = 0.9804 เท่าเดิม: จากกราฟรูป 5.1 (เส้น n = 2, 1 - XA = 0.02) หรือคำนวณจากสูตร:
(τ CA0)m / (τ CA0)p = [XA/(1-XA)2] / [XA/(1-XA)] = 1 / (1 - XA) = 1 / 0.0196 ≈ 51
ดังนั้น τm = 51 × τp = 51 × 5 = 255 min ⇒ VCSTR = v × τm = 0.10 L/min × 255 min = 25.5 L (ใหญ่กว่า PFR ถึง 51 เท่า)
(ค) ถ้า VCSTR = VPFR = 0.5 L (τm = 5 min): k CA0 τm = 50
จากสมการ CSTR: k CA0 τm = XA / (1 - XA)2 ⇒ 50(1 - XA)2 = XA ⇒ 50 XA2 - 101 XA + 50 = 0
แก้สมการกำลังสองได้ XA ≈ 0.865 (86.5%) (ต่ำกว่า PFR ที่ทำได้ 98.04% มาก)

ปฏิกิริยาอันดับสอง, XA = 0.95 (1 - XA = 0.05), เพิ่มถังขนาด V เท่าเดิมอีก 1 เครื่อง:
(ก) เครื่องปฏิกรณ์ท่อไหล (PFR):
- ต่อแบบขนาน: ป้อนเข้าแต่ละถัง FA0 รวมเป็น 2 FA0 ⇒ กำลังการผลิตเพิ่มขึ้น 2.0 เท่า
- ต่อแบบอนุกรม: ปริมาตรรวมเป็น 2V โดย τp = Vรวม / vใหม่ ⇒ เพื่อให้ได้ XA = 0.95 เท่าเดิม ค่า τp ต้องเท่าเดิม ดังนั้น vใหม่ = 2V / τp = 2 vเดิม ⇒ กำลังการผลิตเพิ่มขึ้น 2.0 เท่า (เท่ากันทั้งขนานและอนุกรม)
(ข) เครื่องปฏิกรณ์ถังกวน (CSTR):

คำถาม #1 (เพิ่มเป็น N = 4 ถังอนุกรม, อันดับสอง): จากกราฟรูป 5.7 ที่ 1 - XA = 0.05 อ่านเส้น N = 4 ได้ (k CA0 τ)4 ≈ 25

เฉลยตัวอย่างที่ 6.1 (สไลด์บทที่ 6 หน้า 30-33):
หา Selectivity บัดดล: SR = r1 / r2 = (k1 CA1.8 CB0.5) / (k2 CA0.3 CB1.5) = (k1/k2) · CA1.5 / CB
เพื่อให้ได้ SR สูงสุด ต้องควบคุมให้ CA สูง และ CB ต่ำ ตลอดเวลา
- เครื่องปฏิกรณ์แบบกะ: ใส่สาร A ทั้งหมดลงในถังไว้ก่อน แล้วค่อยๆ หยดป้อนสาร B ลงไปทีละน้อยอย่างช้าๆ
- เครื่องปฏิกรณ์แบบไหลต่อเนื่อง: ให้สายหลักของสาร A ไหลเข้าท่อ PFR แล้วเจาะท่อป้อนสาร B เสริมเข้ามาทีละน้อยหลายๆ จุดตามความยาวท่อ
เฉลยตัวอย่างท้ายบทที่ 6 ข้อ 1 (สไลด์บทที่ 6 หน้า 60-63):
A →k1 R →k2 S โดย k1 = k2 = 0.1 min-1, CA0 = 1 mol/L, v = 1,000 L/h
(ก) PFR: τp,max = 1 / k = 1 / 0.1 = 10 min (1/6 h)
CR,max / CA0 = 1 / e ≈ 0.368 ⇒ CR,max = 0.368 mol/L
ขนาดเครื่อง: VPFR = v · τp,max = 1,000 × (1/6) = 166.7 L
(ข) CSTR: τm,max = 1 / √(k1 k2) = 1 / 0.1 = 10 min (1/6 h)
CR,max / CA0 = 1 / [1 + √(k2/k1)]2 = 1 / (1 + 1)2 = 0.25 ⇒ CR,max = 0.25 mol/L
ขนาดเครื่อง: VCSTR = 1,000 × (1/6) = 166.7 L (ได้ผลผลิตสาร R ต่ำกว่า PFR เนื่องจากอิทธิพลของ Back-mixing)
เฉลยตัวอย่างท้ายบทที่ 6 ข้อ 2 (สไลด์บทที่ 6 หน้า 64-74):
A → R (rR = 2 CA), 2A → S (rS = 0.4 CA2, -rA = 2 CA + 0.4 CA2), CA0 = 10, XA = 0.8 ⇒ CAf = 2 kmol/m3
Selectivity: SR = rR / rS = 2 CA / (0.4 CA2) = 5 / CA ⇒ ยิ่ง CA ต่ำ SR ยิ่งสูง ดังนั้น CSTR จะให้ Yield รวมสูงกว่า PFR
- CSTR: ȲR = YR|CAf=2 = 2(2) / [2(2) + 0.4(2)2] = 4 / 5.6 = 0.714
CRf = ȲR(CA0 - CAf) = 0.714 × 8 = 5.71 kmol/m3, CSf = 0.5(8 - 5.71) = 1.15 kmol/m3, τm = (10 × 0.8) / 5.6 = 1.43 h
- PFR: CRf = -∫102 [2 CA / (2 CA + 0.4 CA2)] dCA = 5 ln(3.0 / 1.4) = 3.81 kmol/m3
ȲR = 3.81 / 8 = 0.476, CSf = 0.5(8 - 3.81) = 2.10 kmol/m3, τp = 0.5 ln[(10 × 7)/(2 × 15)] = 0.424 h

เฉลยตัวอย่างที่ 8.1: การพิสูจน์ Langmuir Competitive Adsorption (สไลด์บทที่ 8 หน้า 55-59):
การดูดซับ: X + S ↔ X·S และ Y + S ↔ Y·S โดยที่ rnet,X = kAdX pX CV - k-AdX CX·S = 0 ที่สมดุล
จะได้ CX·S = KX pX CV และในทำนองเดียวกัน CY·S = KY pY CV (โดย Ki = kAdi / k-Adi)
สมดุลมวลของจุดกัมมันต์ทั้งหมด (Site Balance): CT = CV + CX·S + CY·S
แทนค่า CX·S และ CY·S: CT = CV + KX pX CV + KY pY CV = CV (1 + KX pX + KY pY)
หา CV: CV = CT / (1 + KX pX + KY pY)
หาสัดส่วนการปกคลุมผิว θX = CX·S / CT = (KX pX CV) / CT:
θX = (KX pX) / (1 + KX pX + KY pY) และ θY = (KY pY) / (1 + KX pX + KY pY) [ซ.ต.พ.]
เฉลยตัวอย่างที่ 8.2: การวิเคราะห์กลไกปฏิกิริยาบนตัวเร่งปฏิกิริยา (สไลด์บทที่ 8 หน้า 69-73):
กำหนดให้ Surface Reaction เป็นขั้นตอนควบคุมอัตราเร็ว (Rate Determining Step: RDS):
roverall = rRe = kR θA - k-R θC
เนื่องจากขั้นตอนการดูดซับ A และการคายซับ C เกิดขึ้นเร็วมาก จึงถือว่าอยู่ที่สมดุลเสมอ:
- จาก rAd = kA pA θV - k-A θA = 0 ⇒ θA = (kA/k-A) pA θV = KAd pA θV
- จาก rDe = kD θC - k-D pC θV = 0 ⇒ θC = (k-D/kD) pC θV = K′De pC θV
จากความสัมพันธ์ของพื้นผิวทั้งหมด: θV + θA + θC = 1
แทนค่า: θV (1 + KAd pA + K′De pC) = 1 ⇒ θV = 1 / (1 + KAd pA + K′De pC)
แทน θA และ θC ลงในสมการอัตราเร็วรวม จะได้สมการอัตราเร็วในรูปความดันย่อย:
roverall = (kR KAd pA - k-R K′De pC) / (1 + KAd pA + K′De pC)
เฉลยประเด็นงานวิจัยบทที่ 9: กลไกและประสิทธิภาพของวัสดุดักจับก๊าซ CO2:
1. Chitosan/Activated Carbon Beads (สไลด์บทที่ 9 หน้า 3-5, 20-38):
- Physisorption: ก๊าซ CO2 แพร่เข้าสู่รูพรุนแบบลำดับชั้น (Hierarchical pores) ทั้ง Macropores (>50 nm), Mesopores (2-50 nm) และ Micropores (<2 nm) ของถ่านกัมมันต์จากกากกาแฟ (Activated Coffee Grounds: ACG)
- Chemisorption: อาศัยหมู่อะมิโนอิสระ (-NH2) บนสายโซ่ของไคโตซานเกิดพันธะกับ CO2 เป็นเกลือคาร์บาเมต (Carbamate)
- ผลการทดลอง: การเพิ่ม ACG (40%w/w) และ Epichlorohydrin (EP 7.16-8 g) เพิ่มความสามารถในการดูดซับ CO2 สูงสุดเป็น 7.62-7.73 cm3/g
2. Fe-MOFs จากกากสะเก็ดเหล็กรีดร้อน (Mill Scale Waste) (เอกสารงานวิจัย รศ.อาชาไนย บัวศรี):
- กระบวนการ In-situ Acid-assisted: ตัวอย่าง MF1.5 ดูดซับ CO2 ได้ 21.60 cc/g สูงกว่ากากสะเก็ดเหล็กดิบ (2.70 cc/g) ถึง 8 เท่า
- กระบวนการ Pre-leaching: การสกัดไอออน Fe3+ ด้วยกรด HCl ก่อนสังเคราะห์ ช่วยสร้างผลึก MOF ที่สมบูรณ์และเพิ่มพื้นที่ผิว BET สูงถึง 1,213 m2/g ส่งผลให้ค่าการดูดซับ CO2 พุ่งสูงขึ้นเป็น 50.12 cc/g (เพิ่มขึ้น 9-18 เท่า)
