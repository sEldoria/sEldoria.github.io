คู่มือวิชาการและการเตรียมสอบเรื่อง โครมาโทกราฟี (Chromatography)

หลักการแยกสาร, ทฤษฎีเพลต (Plate Theory), ทฤษฎีอัตรา (Rate Theory), เทคนิค GC, HPLC และการคำนวณโครมาโทแกรม

1. บทนำและหลักการพื้นฐานของโครมาโทกราฟี (Fundamentals of Chromatography)

โครมาโทกราฟี (Chromatography): คือเทคนิคการแยกสารผสม (mixture) ที่ประกอบด้วยสารหลายชนิดออกจากกันเป็นส่วนๆ โดยอาศัยความแตกต่างของสมบัติการละลายใน เฟสเคลื่อนที่ (Mobile Phase) และความสามารถในการถูกดูดซับหรือกระจายตัวบน เฟสที่อยู่กับที่ (Stationary Phase) สารตัวอย่าง (Analyte) จะเกิดสมดุลการกระจายตัว (Equilibrium distribution: Amobile ⇄ Astationary) ตลอดความยาวของคอลัมน์ โดยสารที่ละลายใน mobile phase ได้ดีและถูก stationary phase ยึดเหนี่ยวไว้น้อยจะถูกชะ (elute) ออกมาก่อน ส่วนสารที่ยึดติดกับ stationary phase ได้ดีจะเคลื่อนที่ออกมาทีหลัง

คำศัพท์พื้นฐานสำคัญ (Chromatographic Glossary):
• Analyte: สารที่ต้องการแยกและวิเคราะห์ในของผสม
• Eluent: สารละลายหรือแก๊สพา (Mobile phase) ที่ใช้พา analyte
• Eluate: ของไหลที่ไหลชะออกมาจากปลายคอลัมน์ (Solvent + Analyte)
• Support: อนุภาคของแข็งเฉื่อยที่ใช้เคลือบ stationary liquid

2. การจำแนกประเภทของโครมาโทกราฟี (Classification of Chromatography)

กลไกการแยก (Mechanism) เฟสอยู่กับที่ / เฟสเคลื่อนที่ หลักการทำงานและอันตรกิริยา (Separation Principle)
1. Adsorption Solid / Liquid or Gas อาศัยการดูดซับบนพื้นผิวของแข็งที่มีรูพรุน (เช่น Silica gel, Alumina) ด้วยแรงดึงดูดทางขั้ว
2. Partition Liquid film / Liquid or Gas อาศัยการกระจายตัวและการละลายที่แตกต่างกันระหว่างของเหลว 2 เฟสที่ไม่ผสมกัน (LLC / GLC)
3. Ion Exchange (IEC) Ion resin / Liquid อาศัยแรงดึงดูดทางไฟฟ้าสถิตระหว่างไอออนบนเรซินกับไอออนที่มีประจุตรงข้ามของสารตัวอย่าง
4. Size Exclusion (SEC/GPC) Porous gel / Liquid ไม่มีแรงอันตรกิริยาเคมี อาศัยขนาดโมเลกุล โมเลกุลใหญ่ถูกคัดออก (excluded) จึงออกมาก่อน โมเลกุลเล็กเข้าตามรูพรุนจึงออกมาช้า
5. Affinity Immobilized ligand / Liquid อาศัยความจำเพาะเจาะจงทางชีวโมเลกุลสูงมาก เช่น แอนติเจน-แอนติบอดี หรือเอนไซม์-ซับสเตรต

Normal Phase vs. Reverse Phase

• Normal (Forward) Phase: Stationary phase มีขั้วสูง (Polar เช่น Silica gel), Mobile phase ไม่มีขั้ว (Non-polar เช่น Hexane) สารไม่มีขั้วจะออกมาก่อน
• Reverse Phase: Stationary phase ไม่มีขั้ว (Non-polar เช่น C-18, C-8 บน Silica), Mobile phase มีขั้ว (Polar เช่น น้ำ, เมทานอล) สารมีขั้วจะออกมาก่อน

Columnar vs. Planar Chromatography

• Columnar: บรรจุ Stationary phase ในท่อทรงกระบอกแคบ พาด้วยแรงดันหรือแรงโน้มถ่วง เช่น HPLC, GC
• Planar: เคลือบ Stationary phase บนแผ่นรองรับแบน เช่น Thin Layer Chromatography (TLC), Paper chromatography โดยอาศัยแรงแคปิลลารี

3. การอ่านโครมาโทแกรมและพารามิเตอร์พื้นฐาน (Chromatographic Parameters)

โครมาโทแกรม (Chromatogram): คือกราฟแสดงความสัมพันธ์ระหว่างสัญญาณของตัวตรวจวัด (Detector Signal) กับเวลา (Time, t) หรือปริมาตรของเฟสเคลื่อนที่ (Volume, V) ข้อมูลจากโครมาโทแกรมใช้ทั้งการวิเคราะห์เชิงคุณภาพ (Qualitative จาก tR) และเชิงปริมาณ (Quantitative จากพื้นที่ใต้พีก Peak Area หรือความสูงพีก Peak Height)

M (dead time) Analyte Peak (tR) Baseline width (W) W1/2 Adjusted retention time (t'R = tR - tM)

พารามิเตอร์หลักในการวิเคราะห์และสมการสำคัญ

พารามิเตอร์ สมการคำนวณ ความหมายและการนำไปแปลผล
Dead Time (tM หรือ t0) tM = L / u เวลาที่สารที่ไม่ถูกยึดจับเลย (Unretained species) เคลื่อนที่ผ่านคอลัมน์
Retention Time (tR) tR = t'R + tM เวลารวมตั้งแต่ฉีดสารจนถึงจุดกึ่งกลางยอดพีก ใช้ระบุเอกลักษณ์ของสาร (Qualitative)
Retention Factor (k') k' = (tR - tM) / tM = t'R / tM อัตราส่วนเวลาที่สารอยู่บน stationary phase เทียบกับ mobile phase (ค่าที่เหมาะสมคือ 1–10)
Selectivity Factor (α) α = t'R,B / t'R,A = k'B / k'A ความสามารถในการแยกสาร 2 ชนิด (สาร B ออกทีหลังสาร A ดังนั้น α ≥ 1 เสมอ โดย α ≥ 1.1 แยกได้ดี)

รูปร่างของพีกและความไม่สมมาตร (Peak Shapes)

• Gaussian Peak: สมมาตรสมบูรณ์แบบ (Asymmetry factor, As = 1.0)
• Tailing Peak (As > 1.0): ท้ายพีกย้อย เกิดจากการมี active sites บน stationary phase หรือเกิดการดูดซับรุนแรง
• Fronting Peak (As < 1.0): หน้าพีกเอียงเท เกิดจากการฉีดสารตัวอย่างเข้มข้นเกินไปจนคอลัมน์อิ่มตัว (Column overload)

เกณฑ์ของค่า k' (Capacity Factor) ในการแยก

• k' < 1: สารเคลื่อนที่ออกมาเร็วเกินไป พีกจะซ้อนทับกับ dead time peak ทำให้แยกสารไม่ได้
• 1 ≤ k' ≤ 10: ช่วงที่เหมาะสมที่สุด พีกแยกตัวดีและใช้เวลาวิเคราะห์สั้น
• k' > 20: สารติดอยู่ในคอลัมน์นานเกินไป พีกเตี้ยและกว้าง เสียเวลาในการวิเคราะห์โดยไม่จำเป็น

4. ทฤษฎีเพลตและประสิทธิภาพของคอลัมน์ (Plate Theory)

เสนอโดย Martin และ Synge (1941) โดยอนุมานเปรียบเทียบคอลัมน์โครมาโทกราฟีเสมือนกับ หอกลั่นลำดับส่วน (Fractional Distillation Column) ที่แบ่งออกเป็นชั้นตามทฤษฎีเล็กๆ เรียกว่า Theoretical Plate (N) ซึ่งในแต่ละเพลตจะเกิดสมดุลการกระจายตัวของสารระหว่างเฟสเคลื่อนที่และเฟสอยู่กับที่หนึ่งครั้ง เพลตนี้ไม่มีอยู่จริงทางกายภาพแต่เป็นตัวเลขเชิงจินตนาการเพื่อประเมิน ประสิทธิภาพของคอลัมน์ (Column Efficiency)

สมการคำนวณจำนวนเพลต (N) และความสูงของเพลต (H):
N = 16 (tR / W)2 = 5.54 (tR / W1/2)2
H = L / N = (L / 16) · (W / tR)2
เมื่อ L = ความยาวของคอลัมน์, W = ความกว้างที่ฐานพีก, W1/2 = ความกว้างที่กึ่งกลางความสูงของพีก (หน่วยเวลาต้องตรงกัน)
กฎทองของประสิทธิภาพคอลัมน์ (Golden Rule of Column Efficiency): คอลัมน์ที่มีประสิทธิภาพการแยกสูงและให้พีกแคบคมชัด จะต้องมี จำนวนเพลตตามทฤษฎีมาก (N สูง, ปกติ N > 2,000) และมี ความสูงของแต่ละเพลตน้อย (HETP หรือ H ต่ำ)

5. ค่าการแยกของสารสองชนิด (Resolution, Rs)

Resolution (Rs): เป็นค่าที่บ่งบอกความสามารถของระบบในการแยกพีกของสารสองชนิด (A และ B) ออกจากกันอย่างแท้จริง โดยนำทั้งผลต่างของ retention time และความกว้างของพีกมาร่วมพิจารณา

สมการคำนวณ Resolution (Rs):
Rs = 2(tR,B - tR,A) / (WA + WB) = 2Δt / (WA + WB) Rs = (√N / 4) · (α - 1) · [k'B / (1 + k'B)]

เกณฑ์การตัดสินค่า Resolution (Rs)

• Rs < 1.0: พีกซ้อนทับกันค่อนข้างมาก ไม่สามารถแยกสารได้สมบูรณ์
• Rs = 1.0: พีกแยกกันประมาณ 98% (ยอดพีกแยกแต่ฐานยังติดกัน)
• Rs ≥ 1.5: Baseline Separation (การแยกที่ฐานพีกอย่างสมบูรณ์) สารแยกกัน 99.7% ซึ่งเป็นเกณฑ์มาตรฐานในทางวิเคราะห์
• Rs > 10: แยกห่างเกินไป ทำให้เปลืองเวลาและตัวทำละลายโดยไม่จำเป็น

3 ปัจจัยที่ควบคุมค่า Resolution (Purnell Equation)

1. Efficiency Factor (√N): เพิ่ม N ทำได้โดยใช้คอลัมน์ที่ยาวขึ้น หรืออนุภาคเล็กลง (ลด H)
2. Selectivity Factor (α): ควบคุมระยะห่างของพีก ปรับเปลี่ยนได้โดยเปลี่ยนชนิดของ stationary phase หรือตัวทำละลาย
3. Retention Factor (k'): ปรับเปลี่ยนโดยการควบคุมอุณหภูมิ (ใน GC) หรือเปลี่ยนสัดส่วนตัวทำละลาย (ใน HPLC)

6. ทฤษฎีอัตราและสมการแวนดีมเตอร์ (Rate Theory & Van Deemter Equation)

เสนอโดย J.J. Van Deemter (1956) เพื่ออธิบายสาเหตุเชิงพลศาสตร์ที่ทำให้เกิด การขยายตัวของแถบสาร (Band Broadening หรือ Peak Dispersion) ขณะเคลื่อนที่ผ่านคอลัมน์ ซึ่งทฤษฎีเพลตไม่สามารถอธิบายได้ การที่พีกยิ่งกว้างแสดงว่าประสิทธิภาพการแยกยิ่งต่ำ สมการ Van Deemter แสดงความสัมพันธ์ระหว่าง Plate Height (H) กับความเร็วเชิงเส้นของ mobile phase (u):

H = A + (B / u) + C · u
พจน์ในสมการ กลไกการเกิด Band Broadening วิธีลดค่าเพื่อเพิ่มประสิทธิภาพคอลัมน์ (ลด H)
A term
(Eddy Diffusion)		 โมเลกุลของสารชนิดเดียวกันเดินทางผ่านช่องว่างระหว่างอนุภาคที่มีเส้นทางยาวไม่เท่ากัน (Multiple flow paths) • บรรจุคอลัมน์ให้สม่ำเสมอ (Uniform packing)
• ลดขนาดอนุภาค (Smaller particle size)
• ใน Capillary Column เทอม A = 0 เพราะไม่มีของแข็งบรรจุ
B / u term
(Longitudinal Diff.)		 การแพร่ของสารจากบริเวณกึ่งกลางแถบที่มีความเข้มข้นสูงไปยังหัว-ท้ายแถบที่มีความเข้มข้นต่ำตามทิศทางการไหล • เพิ่มอัตราการไหล (u สูงขึ้น) เพื่อลดเวลาที่สารแช่อยู่ในคอลัมน์
• ลดอุณหภูมิคอลัมน์ (เทอม B เด่นชัดมากใน GC เพราะแก๊สแพร่เร็ว)
C · u term
(Mass Transfer)		 ความล่าช้าในการถ่ายโอนมวลและเกิดสมดุลระหว่าง mobile phase กับ stationary phase (โมเลกุลในรูพรุนลึกจะออกมาช้า) • ใช้ฟิล์ม stationary liquid ให้บางลง (Thinner film)
• ลดขนาดอนุภาค หรือใช้อุณหภูมิสูงขึ้นช่วยเร่งสมดุล
• ลดอัตราการไหล (u ต่ำลง) เพื่อให้สารมีเวลาถ่ายโอนมวลเข้าสู่สมดุล

กราฟ Van Deemter Plot และความเร็วที่เหมาะสม (uopt)

เมื่อพล็อตค่า H เทียบกับ u กราฟจะมีลักษณะเป็นรูปตัว U:
• ที่ u ต่ำมาก: เทอม B/u จะมีค่าสูงมาก ทำให้ H สูง (พีกกว้าง)
• ที่ u สูงมาก: เทอม C·u จะมีค่าสูงมาก ทำให้ H สูงขึ้นเช่นกัน
• จุดต่ำสุดของกราฟ (uopt): คือความเร็วที่ให้ค่า H ต่ำที่สุด ส่งผลให้คอลัมน์มีประสิทธิภาพสูงสุด (N สูงสุด)

ความแตกต่างระหว่าง GC และ LC ในมุมมอง Rate Theory

• ใน GC: สัมประสิทธิ์การแพร่ในแก๊สสูงกว่าของเหลว 104 เท่า ดังนั้น เทอม B จึงมีอิทธิพลสูงมาก จึงไม่ควรใช้อัตราการไหลที่ช้าเกินไปใน GC
• ใน LC (HPLC): การแพร่ในของเหลวช้ามาก เทอม B จึงน้อย แต่ เทอม C มีอิทธิพลสูง อนุภาคขนาดเล็กมาก (3–5 µm) ใน HPLC จึงช่วยลดทั้งเทอม A และ C ได้อย่างดีเยี่ยม

7. แก๊สโครมาโทกราฟี (Gas Chromatography - GC)

แก๊สโครมาโทกราฟี (GC): ใช้สำหรับแยกสารผสมที่สามารถระเหยกลายเป็นไอได้โดยไม่สลายตัวที่อุณหภูมิไม่เกิน 450 °C โดยมีเฟสเคลื่อนที่เป็นแก๊สเฉื่อย เรียกว่า Carrier Gas (เช่น He, N2, Ar ความบริสุทธิ์ ≥ 99.995%) ทำหน้าที่พาสารตัวอย่างผ่านเข้าไปในคอลัมน์ที่ติดตั้งอยู่ในตู้อบควบคุมอุณหภูมิ (Oven)

คุณลักษณะ Packed Column (คอลัมน์แบบบรรจุ) Capillary / Open Tubular Column
โครงสร้างภายใน บรรจุอนุภาคของแข็งเฉื่อยที่เคลือบ stationary liquid ท่อกลวง ภายในเคลือบฟิล์มของเหลวบาง (0.25–3.0 µm) ที่ผนังท่อ
ขนาดเส้นผ่านศูนย์กลาง (ID) กว้าง 3 – 8 mm แคบมาก 0.1 – 0.53 mm
ความยาวของคอลัมน์ สั้น 1 – 3 เมตร ยาวมาก 25 – 100 เมตร
ประสิทธิภาพ (Efficiency) N ต่ำกว่า เกิด Eddy diffusion (A ≠ 0) N สูงมาก (ระดับแสนเพลต), ไม่มี Eddy diffusion (A = 0)
ความดันต้านทาน (Pressure drop) สูงเนื่องจากมีอนุภาคอัดแน่น ต่ำมากเนื่องจากเป็นท่อกลวง ทำให้ใช้คอลัมน์ยาวๆ ได้

อิทธิพลของอุณหภูมิคอลัมน์ใน GC (Column Temperature)

• เพิ่มอุณหภูมิ: สารระเหยเป็นไอมากขึ้น ค่า partition coefficient (K) ลดลง สารเคลื่อนที่เร็วขึ้น วิเคราะห์ได้เร็ว แต่พีกอาจเบียดชิดกัน (Resolution ลดลง)
• ลดอุณหภูมิ: สารจับกับ stationary liquid นานขึ้น ทำให้ Resolution ดีขึ้น แต่ใช้เวลานานขึ้น
• นิยมใช้การโปรแกรมอุณหภูมิ (Temperature Programming) ค่อยๆ เพิ่มความร้อนเพื่อแยกทั้งสารจุดเดือดต่ำและจุดเดือดสูงในรันเดียว

ตัวตรวจวัด Flame Ionization Detector (FID)

• เป็น Detector ยอดนิยมสำหรับสารประกอบอินทรีย์ไฮโดรคาร์บอนเกือบทุกชนิด
• หลักการ: เผาสารที่ออกมาจากคอลัมน์ด้วยเปลวไฟของแก๊สไฮโดรเจน (H2) ผสมกับอากาศ (Air) ทำให้เกิดไอออนประจุบวก แล้วถูกดึงดูดไปที่ Collector electrode เกิดกระแสไฟฟ้าที่เป็นสัดส่วนโดยตรงกับจำนวนคาร์บอนอะตอม
• ข้อจำกัด: เป็นตัวตรวจวัดแบบทำลายสาร (Destructive detector)

การวิเคราะห์พอลิเมอร์ด้วย GC: พอลิเมอร์เป็นโมเลกุลขนาดใหญ่และไม่ระเหย หากต้องการวิเคราะห์โครงสร้างหรือองค์ประกอบ ต้องใช้เทคนิค Pyrolysis-GC (Py-GC) โดยใช้ความร้อนสูงทำให้สายโซ่พอลิเมอร์แตกตัวเป็นสารโมเลกุลเล็กที่ระเหยได้ก่อนเข้าคอลัมน์

8. โครมาโทกราฟีของเหลวสมรรถนะสูง (HPLC)

HPLC (High Performance Liquid Chromatography): พัฒนามาจากคอลัมน์โครมาโทกราฟีแบบดั้งเดิม โดยเปลี่ยนจากการปล่อยให้ของเหลวไหลด้วยแรงโน้มถ่วง มาเป็นการใช้ ปั๊มแรงดันสูง (High Pressure Pump) ผลัก mobile phase ผ่านคอลัมน์ที่บรรจุอนุภาคขนาดเล็กมาก (3–20 µm) ทำให้การแยกสารมีประสิทธิภาพสูงมาก รวดเร็ว และสามารถวิเคราะห์สารที่ไม่ทนความร้อนหรือไม่ระเหยได้

องค์ประกอบของเครื่อง HPLC หน้าที่การทำงานและหลักการทางวิศวกรรมเคมี
1. Solvent Reservoir & Degasser บรรจุ mobile phase และมีระบบไล่ฟองแก๊สที่ละลายอยู่ออก ป้องกันไม่ให้เกิดฟองแก๊สในปั๊มและ detector
2. High Pressure Pump สร้างแรงดันสูง (สูงถึงหลายร้อยบาร์) และควบคุมอัตราการไหลของตัวทำละลายให้คงที่แม่นยำสม่ำเสมอ
3. Sample Injection (Rheodyne Valve) ใช้ระบบ Sample Loop มี 2 ตำแหน่ง: ตำแหน่ง Load สำหรับฉีดสารเติมเข้า loop และหมุนไปที่ Inject เพื่อให้ mobile phase ชะสารเข้าสู่คอลัมน์ ให้ความเที่ยงตรงสูงมาก
4. Chromatographic Column ท่อสแตนเลสสั้น (10–35 cm, ID 1–10 mm) บรรจุอนุภาค Silica หรือ Polymer beads ขนาดเล็กระดับไมโครเมตร
5. Detector ตรวจวัดสัญญาณสารที่ถูกชะออกมา เช่น UV-Vis Absorption Detector, Refractive Index Detector (RI)

การแยกแบบ Isocratic vs. Gradient Elution

• Isocratic Elution: ใช้องค์ประกอบของ Mobile phase สัดส่วนคงที่ตลอดการรัน เหมาะกับของผสมที่สารมีขั้วใกล้เคียงกัน
• Gradient Elution: ค่อยๆ ปรับเปลี่ยนสัดส่วนของตัวทำละลายระหว่างการรัน (เช่น ค่อยๆ เพิ่มตัวทำละลายที่มีแรงชะสูงขึ้น) ช่วยให้สารที่ติดแน่นหลุดออกมาเร็วขึ้น ลดเวลาวิเคราะห์และทำให้พีกแคบคมชัด

การวิเคราะห์เชิงคุณภาพและปริมาณ (Qual & Quant)

• เชิงคุณภาพ (Qualitative): เทียบค่า Retention Time (tR) กับสารมาตรฐาน หรือใช้เทคนิค Spiking (เติมสารบริสุทธิ์ที่สงสัยลงในตัวอย่าง หากพีกใดสูงขึ้น แสดงว่าเป็นพีกของสารนั้น)
• เชิงปริมาณ (Quantitative): สร้างกราฟมาตรฐาน (Calibration Curve) ระหว่างความเข้มข้นกับพื้นที่ใต้พีก (Peak Area) กราฟต้องเป็นเส้นตรงและผ่านจุดกำเนิด

สรุปเปรียบเทียบข้อเด่น: GC vs HPLC
• GC: เหมาะกับสารโมเลกุลเล็ก ระเหยง่าย ทนความร้อน ประสิทธิภาพแยกสูงมากด้วย capillary column
• HPLC: เหมาะกับสารโมเลกุลใหญ่ สารชีวโมเลกุล สารที่ไม่ทนความร้อน และพอลิเมอร์ที่ละลายน้ำหรือตัวทำละลายได้

9. สรุปความสัมพันธ์ของสมการและคลังข้อสอบปรนัย (Exam Part 1)

สูตรทั้งหมดที่ระบุในคำชี้แจงหน้าข้อสอบ มีความเชื่อมโยงกันอย่างเป็นระบบเพื่อใช้ประเมินประสิทธิภาพและพฤติกรรมการแยกสาร:

ชุดสมการมาตรฐานที่ระบุในใบข้อสอบ (Exam Formula Reference):
• k' = (tR - tM) / tM = t'R / tM = mS / mM = K / β
• N = L / H = 16 (tR / W)2 = 5.54 (tR / W1/2)2
• α = (t'R)B / (t'R)A = k'B / k'A = KB / KA
• H = σ2 / L = σ2L / tR2 = (L / 16)(W / tR)2
• Rs = (tRB - tRA) / [(WA + WB) / 2] = 2Δt / (WA + WB)

ชุดข้อสอบปรนัย 4 ตัวเลือก เสมือนจริง (พร้อมวิเคราะห์เฉลยละเอียด)

ข้อ 1.1: ปัจจัยใดต่อไปนี้มีผลทำให้เทอม Eddy Diffusion (A-term) ในสมการ Van Deemter มีค่าลดลงมากที่สุด?

(ก) การเพิ่มอุณหภูมิของตู้อบคอลัมน์ใน Gas Chromatography
(ข) การลดขนาดอนุภาคของเฟสอยู่กับที่และบรรจุคอลัมน์ให้มีความสม่ำเสมอสูง
(ค) การเพิ่มอัตราเร็วเชิงเส้นของเฟสเคลื่อนที่ (u) ให้สูงขึ้น
(ง) การเพิ่มความหนาของฟิล์มของเหลวที่เคลือบบนผิวของแข็ง

เฉลย: ตอบ (ข)
คำอธิบาย: เทอม A (Eddy diffusion) เกิดจากโมเลกุลเดินทางหลายเส้นทางที่ไม่เท่ากัน การใช้อนุภาคขนาดเล็กและสม่ำเสมอจะช่วยลดความแตกต่างของระยะทางเดิน (Path length) ลงได้มากที่สุด และหากใช้ Capillary column เทอม A จะกลายเป็นศูนย์ทันที

ข้อ 1.2: หากสารตัวอย่าง A และ B มีค่า Retention factor k'A = 2.0 และ k'B = 4.0 จงหาค่า Selectivity factor (α)?

(ก) 0.50          (ข) 1.50          (ค) 2.00          (ง) 6.00

เฉลย: ตอบ (ค)
คำอธิบาย: ตามสูตร α = k'B / k'A โดยกำหนดให้สาร B คือสารที่ถูกยึดจับดีกว่า (k' มากกว่า) เสมอ ดังนั้น α = 4.0 / 2.0 = 2.00 (ค่า α ต้อง ≥ 1.0 เสมอ)

ข้อ 1.3: ในการทดสอบ HPLC เมื่อเปลี่ยนการชะจาก Isocratic Elution เป็น Gradient Elution มีวัตถุประสงค์หลักเพื่ออะไร?

(ก) ป้องกันไม่ให้สารตัวอย่างเกิดปฏิกิริยากับคอลัมน์
(ข) เพิ่มความดันในระบบให้คงที่ตลอดการทดสอบ
(ค) เร่งให้สารที่ถูกยึดจับแน่นหลุดออกมาเร็วขึ้น ลดเวลาการวิเคราะห์ และป้องกันพีกขยายกว้าง (Band broadening)
(ง) เปลี่ยนแปลงกลไกการแยกจาก Reverse Phase ไปเป็น Normal Phase

เฉลย: ตอบ (ค)
คำอธิบาย: การใช้ Gradient elution โดยการค่อยๆ ปรับเพิ่มสัดส่วนตัวทำละลายที่มีแรงชะสูงขึ้น จะทำให้สารที่มี retention นานหลุดออกมาเร็วขึ้น พีกที่ปลายโครมาโทแกรมจะคมชัดและประหยัดเวลาอย่างมาก

10. ชุดข้อสอบคำนวณจากโครมาโทแกรม พร้อมวิธีคิดอย่างละเอียด (Exam Part 2)

ข้อสอบข้อที่ 2 ของอาจารย์ให้นำไม้บรรทัดและเครื่องคิดเลขเข้าห้องสอบ เพื่อวัดและคำนวณค่าจากโครมาโทแกรมที่กำหนดให้:

โจทย์ข้อสอบคำนวณเสมือนจริง: การวิเคราะห์โครมาโทแกรมของสารผสมสองชนิด

นักศึกษานำสารตัวอย่างผสมที่มีสาร A และ B มาวิเคราะห์ด้วยเครื่อง HPLC โดยใช้คอลัมน์มีความยาว L = 15.0 cm อัตราการไหลคงที่ จากโครมาโทแกรมวัดระยะด้วยไม้บรรทัดเทียบกับแกนเวลา พบข้อมูลดังนี้:
• พีกของ Unretained solute (tM) ปรากฏที่เวลา tM = 1.50 นาที
• พีกสาร A: จุดยอดพีกปรากฏที่เวลา tR,A = 6.00 นาที, ความกว้างฐานพีก WA = 0.50 นาที, กึ่งกลางความสูง W1/2,A = 0.294 นาที
• พีกสาร B: จุดยอดพีกปรากฏที่เวลา tR,B = 8.50 นาที, ความกว้างฐานพีก WB = 0.70 นาที
คำสั่ง: จงแสดงวิธีคำนวณหาค่าพารามิเตอร์ทั้ง 6 ข้อต่อไปนี้อย่างละเอียด พร้อมระบุหน่วยและสรุปผล

เฉลยและวิธีทำอย่างเป็นขั้นตอน:
1) คำนวณ Corrected Retention Time ของสาร A และ B (t'R):
    • t'R,A = tR,A - tM = 6.00 - 1.50 = 4.50 นาที
    • t'R,B = tR,B - tM = 8.50 - 1.50 = 7.00 นาที
2) คำนวณ Capacity Factor หรือ Retention Factor (k'):
    • k'A = t'R,A / tM = 4.50 / 1.50 = 3.00 (ไร้หน่วย)
    • k'B = t'R,B / tM = 7.00 / 1.50 = 4.67 (ไร้หน่วย)
    (ประเมิน: ค่า k' ทั้งสองอยู่ในช่วง 1–10 แสดงว่าสารทั้งสองถูกชะออกมาในช่วงเวลาที่เหมาะสมมาก)
3) คำนวณ Selectivity Factor (α) ระหว่างสาร B และ A:
    • α = t'R,B / t'R,A = 7.00 / 4.50 ≈ 1.56 (หรือ α = k'B / k'A = 4.67 / 3.00 = 1.56)
    (ประเมิน: ค่า α ≥ 1.1 แสดงว่าคอลัมน์มีความสามารถในการเลือกแยกสาร A และ B ออกจากกันได้ดีมาก)
4) คำนวณจำนวน Theoretical Plates (N) ของสาร A:
    • คำนวณจากสูตรฐานพีก W: N = 16 (tR,A / WA)2 = 16 × (6.00 / 0.50)2 = 16 × (12.0)2 = 16 × 144 = 2,304 เพลต
    • ตรวจทานด้วย W1/2: N = 5.54 (6.00 / 0.294)2 = 5.54 × (20.408)2 ≈ 2,307 เพลต (ตรงกันตามทฤษฎี)
5) คำนวณ Plate Height (H) ของคอลัมน์:
    • H = L / N = 15.0 cm / 2,304 = 0.00651 cm = 0.0651 mm (หรือ 65.1 µm)
6) คำนวณ Resolution (Rs) และสรุปประสิทธิภาพการแยก:
    • Rs = 2(tR,B - tR,A) / (WA + WB) = 2(8.50 - 6.00) / (0.50 + 0.70) = 2(2.50) / 1.20 = 5.00 / 1.20 ≈ 4.17
    สรุปผล: ค่า Rs = 4.17 ซึ่ง มากกว่า 1.5 อย่างมีนัยสำคัญ บ่งบอกว่าสาร A และสาร B เกิดการแยกที่ฐานพีกอย่างสมบูรณ์ (Complete baseline separation) ไม่มีส่วนใดของพีกซ้อนทับกันเลย สามารถนำไปหาปริมาณสาร (Quantitative analysis) จากพื้นที่ใต้พีกได้อย่างแม่นยำ 100%
